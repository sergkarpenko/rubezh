## Межі

- Шаблон перевірено лише розбором скрипта; на живому кроці Vibe новий шаблон ще не перевірено — перший такий крок покаже, чи виконавець пише числа з `--pr` в опис PR без нового коміту.
- Порада «числа з `--pr` — в опис PR» відходить від загальної поради довідника (розділ «PR і чеки») «після останнього пушу опис не чіпати»: там — про числа останніх прогонів після аудиту, тут — про опис одразу після відкриття PR. Джоба `mistral-audit` читає опис на початку прогону, ще до очікування чеків (`scripts/mistral-audit.mjs`), тому правка опису після відкриття PR лишає в першому коментарі рядок «Опис PR змінено після цього прогону», а новий аудит буде лише з наступним пушем. Щоб правка була рідкою, шаблон просить звіряти назву й опис (`--title`, `--body-file`) ще до відкриття PR.
- Перелік кандидатів сесії Claude (документ проєкту claude.ai) цим кроком не оновлено.
