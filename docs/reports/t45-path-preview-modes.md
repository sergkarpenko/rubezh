# Т.45 — «Прев'ю шляху в режимах»: звіт

Малий крок після Т.44 (розділ «Межі» PR 3 у `docs/reports/t44-readable-battlefield.md`): прев'ю шляху (лінія і плашка `<число> AP`) було видно і там, де зону ходу приховано. Один PR класу `approve` (чіпає `src/`), гілка `fix/t45-path-preview-modes`. Код — сесія Claude (відповідь власника).

## Відповіді власника (15.11.2026, кнопками, дослівно)

## Що зроблено

- **Наведення** (`battleCanvasHover` у `src/ui/input.ts`): поки зведено постріл (`ui.fireMode`), гранату чи гель (`ui.itemMode`), наведення шляху не рахує; шлях, що лишився від наведення до зведення, прибирає і перемальовує поле один раз. Рядок `#binfo` у цих режимах наведення більше не переписує — підказка режиму лишається на місці. Плашка шансу над валідною ціллю в режимі пострілу (`aimCell`) — без змін.
- **Малювання** (`renderBattle` у `src/ui/battle.ts`): умова прев'ю шляху тепер та сама, що й у зони ходу, — `ui.fireMode === null && ui.itemMode === null`. Вона ховає шлях одразу після зведення клавішею чи плиткою, ще до першого руху миші.
- **Авто-бій:** наведення, як і раніше, малює шлях і ціну (власник «Авто-бій» не обрав), але `#binfo` не переписує (`deps.autoBusy()`).
- Клік не змінювався: у режимі пострілу клік по порожній клітинці, як і до кроку, знімає режим і дає прев'ю шляху; у режимі гранати й гелю клік обробляє гілка витратника. Правила гри, ядро і сейв — без змін.

## Перевірки

- `src/ui/input.test.ts`, блок «Т.45» — п'ять тестів: без режиму наведення дає шлях, ціну і підказку; зведений постріл — шляху немає, підказку режиму не переписано; граната і гель — те саме; шлях, наведений до зведення, прибирається з однією перемальовкою (і без зайвої на повторному наведенні); авто-бій — шлях є, `#binfo` не переписано.
- `src/ui/battle.test.ts` — один тест: на тій самій фікстурі прев'ю малюється без режиму і не малюється з `fireMode = 'snap'`, `itemMode = 'grenade'`, `itemMode = 'medkit'`.
- **Гейт e2e** (крок «бій: вибрати юніта → рух (тап-тап)», після гейта Т.44): клавіша 1 зводить постріл → наведення на ціль шляху → ті самі точки канви, що були зелені, більше не зелені, текст `#binfo` не змінився; Esc і тап — прев'ю і зелені точки повертаються; далі хід, як раніше.
- Чекліст: `tsc` (три конфігурації), lint, `format:check` — чисто; `npm test` — 1154 тести у 47 файлах; `npm run docs` — 0 помилок; `npm run test:e2e` — зелений. Розмір і клас — в описі PR (`./scripts/pr-size.sh origin/main HEAD`, `./scripts/pr-class.sh origin/main HEAD`).

## Межі

- Чи стало зручніше — оцінює власник на прев'ю гілки.
- В авто-бої прев'ю шляху з ціною лишилось (вибір власника), хоча клік по полю там не працює.
- Режими гранати й гелю в e2e не зачеплено (у загоні сценарію немає витратників) — лише тести модулів.
- На тачі наведення немає: там прев'ю дає перший тап, а тап у режимі пострілу по порожній клітинці знімає режим — без змін.
- Решта кандидата «після Т.44» (плашка над ціллю, розмір тексту на iPad, зона ходу в авто-бої, вузькі гейти e2e Т.44) — не в цьому кроці.
