# Т.75: рядки евакуації в журналах і пастка фокусу у вікнах

Крок закриває хвости Т.71 (межа (в): журнал бою мовчить про евакуацію) і Т.73 (межа (а): Tab виводить фокус з вікна). Код пише сесія Claude (Opus 5.5 medium, ADR-0100).

## Рішення власника (19.11.2026)

- Фініш Т.74, на питання про порядок: «Так, за планом» — Т.75 = рядок евакуації в журналі бою і пастки фокусу у вікнах поверх гри.
- Старт Т.75, кнопками: рядок журналу бою — «⇧ Евакуйовано: Коваль»; рядок журналу партії після місії з результатом «евакуйовано» — «Загін евакуйовано ⇧».

## Що змінилось

- `src/ui/journal.ts`: `battleEventText` для `evac_unit` дає «⇧ Евакуйовано: <ім'я>» (клас порожній); `geoEventText` для `mission_evacuated` — «Загін евакуйовано ⇧».
- `src/main.ts`: `unitName` шукає ім'я ще й у `state.evacuated` — `evacuate` знімає оперативника з поля до події `evac_unit`, і без цього журнал писав id (знахідка 1 аудиту). Слухач `keydown` на Tab. Вікно — перше відкрите в порядку `OVERLAY_ESC_CLOSE` (як для Esc), далі екран перемоги кампанії. Елементи — за селектором `button, input, select, textarea, a[href], [tabindex]:not([tabindex="-1"])`, не вимкнені, без атрибута `hidden` і не під `.hidden`. Tab з останнього — на перший, Shift+Tab з першого — на останній; фокус поза вікном Tab ставить на перший (Shift+Tab — на останній); всередині вікна Tab іде браузеру. Без відкритого вікна подія не скасовується.
- Тести: `src/ui/journal.test.ts` — два тести на тексти; `src/main.ui.test.ts` — чотири: «Меню», «Незбережені зміни», «Налаштування», «Як грати» (на краях кола подію скасовано), без вікна Tab не перехоплено; вимкнена кнопка поза колом і коло діалогу «Нова партія» з полем сіду; рядок журналу бою на сторінці з іменем оперативника.
- `docs/agents/common.md`: дві поради сесії Т.74 після мержу — створення issue через `gh api` і запуск кількох сесій Vibe одним `browser_batch`.

## Перевірки

- `npx tsc --noEmit` (+ `tsconfig.core.json`, `tsconfig.e2e.json`), `npm run lint`, `npm run format:check`, `npm run docs` — без помилок.
- `npm test` — 47 файлів, 1213 тестів (на `main` — 1207); e2e — 3 сценарії.
- Рядків у підрахунку `./scripts/pr-size.sh origin/main HEAD` — 136.
- Навмисні поломки — 6, кожну ловить хоча б один тест Т.75: Shift+Tab з першого ставить фокус на перший; слухач Tab вимкнено; без `preventDefault`; селектор лише `button`; без фільтра вимкнених; `unitName` без `evacuated`.

## Межі

- (а) jsdom сам фокус по Tab не рухає, тому тести перевіряють лише краї кола і повернення ззовні; рух усередині вікна — звичайний Tab браузера.
- (б) Вікно евакуації і екран перемоги кампанії пастку мають (той самий перелік), окремого тесту на них немає. Порядок вікон (як для Esc) тестом не перевірено: два вікна разом зараз не відкриваються («Меню» закривається перед «Незбереженими змінами», «Налаштуваннями» і «Як грати»).
- (г) Вікно без жодного елемента для фокусу Tab блокує повністю — так і має бути для модального вікна; таких вікон зараз немає.
- (в) Рядок журналу бою має той самий вигляд для евакуації з підтвердженням (останній оперативник) і без нього.

## Аудит

Аудитор для мержу (Opus, субагент) на `18ee774` — 10 знахідок (7 перевірених, 3 припущення):
1. Журнал бою писав id замість імені (`unitName` не бачив евакуйованих) — підтверджено, виправлено, тест на сторінці.
2. Тести не ловили зникнення `preventDefault` — підтверджено, на краях кола тест перевіряє `defaultPrevented`.
3. Поля вводу в колі нічим не перевірено — підтверджено, тест діалогу «Нова партія».
4. Не ловились поломки фільтра вимкнених, порядку вікон, `campaign-victory` — фільтр покрито тестом; порядок і екран перемоги — межа (б).
5. Перша частина тесту «Як грати» з однією кнопкою нічого не перевіряє — підтверджено; тепер `tab()` вимагає скасованої події, тож перевіряє.
6. Звіт і опис мовчали про `docs/agents/common.md` — виправлено.
7. Неточний опис селектора — виправлено (селектор наведено дослівно).
8–10. Припущення: порядок вікон за `z-index` (два вікна разом не відкриваються — межа (б)); атрибут `hidden` предків і CSS-приховання (таких елементів у вікнах немає); e2e — пройшов у сесії і в CI.

Mistral на `18ee774` — 1 знахідка (низька): порожнє вікно блокує Tab — відхилено, це поведінка модального вікна (межа (г)), таких вікон немає.
