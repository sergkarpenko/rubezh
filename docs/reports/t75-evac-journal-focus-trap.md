# Т.75: рядки евакуації в журналах і пастка фокусу у вікнах

Крок закриває хвости Т.71 (межа (в): журнал бою мовчить про евакуацію) і Т.73 (межа (а): Tab виводить фокус з вікна). Код пише сесія Claude (Opus 5.5 medium, ADR-0100).

## Рішення власника (19.11.2026)

- Фініш Т.74, на питання про порядок: «Так, за планом» — Т.75 = рядок евакуації в журналі бою і пастки фокусу у вікнах поверх гри.
- Старт Т.75, кнопками: рядок журналу бою — «⇧ Евакуйовано: Коваль»; рядок журналу партії після місії з результатом «евакуйовано» — «Загін евакуйовано ⇧».

## Що змінилось

- `src/ui/journal.ts`: `battleEventText` для `evac_unit` дає «⇧ Евакуйовано: <ім'я>» (клас порожній); `geoEventText` для `mission_evacuated` — «Загін евакуйовано ⇧».
- `src/main.ts`: слухач `keydown` на Tab. Вікно — перше відкрите в порядку `OVERLAY_ESC_CLOSE` (як для Esc), далі екран перемоги кампанії. Елементи — кнопки, поля, посилання і `tabindex` ≥ 0, не вимкнені й не під `.hidden`. Tab з останнього — на перший, Shift+Tab з першого — на останній; фокус поза вікном Tab ставить на перший (Shift+Tab — на останній); всередині вікна Tab іде браузеру. Без відкритого вікна подія не скасовується.
- Тести: `src/ui/journal.test.ts` — два тести на тексти; `src/main.ui.test.ts` — «Меню», «Незбережені зміни», «Налаштування», «Як грати», і перевірка, що без вікна Tab не перехоплено.

## Перевірки

- `npx tsc --noEmit` (+ `tsconfig.core.json`, `tsconfig.e2e.json`), `npm run lint`, `npm run format:check`, `npm run docs` — без помилок.
- `npm test` — 47 файлів, 1211 тестів (на `main` — 1207); e2e — 3 сценарії.
- Рядків у підрахунку `./scripts/pr-size.sh origin/main HEAD` — 93.
- Навмисні поломки (обидві ловлять нові тести): Shift+Tab з першого ставить фокус на перший замість останнього; слухач Tab вимкнено.

## Межі

- (а) jsdom сам фокус по Tab не рухає, тому тести перевіряють лише краї кола і повернення ззовні; рух усередині вікна — звичайний Tab браузера.
- (б) Вікно евакуації і діалог нової партії пастку мають (той самий перелік), окремого тесту на них немає; екран перемоги кампанії — теж без тесту.
- (в) Рядок журналу бою має той самий вигляд для евакуації з підтвердженням (останній оперативник) і без нього.
