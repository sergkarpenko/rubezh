# Т.78: гарматний модуль перехоплювача вручну (кандидат 21)

**Дата:** 19.11.2026 · **Модель:** Opus 5.5 medium · **Тип кроку:** `ui.md`

## Задача
До Т.78 гарматний модуль (протокол «Гарматний модуль перехоплювача», +2 пошкодження за раунд повітряного бою) ставив на перехоплювач лише бот партії. Гравець міг дослідити й виготовити модуль, але в UI бачив тільки «На складі: 1».

## Рішення власника (19.11.2026, кнопками, до реалізації)
1. Кнопка — у панелі «Перехоплювач» (вкладка «База»), поруч із «Ремонт».
2. Модуль можна зняти назад на склад.
3. Безкоштовно й одразу — правило ядра (`installGunModule` / `removeGunModule`, ADR-0058) без змін, баланс не зачеплено.
4. Тексти: «Встановити модуль (+2 пошк.)», «Гарматний модуль: встановлено», «Зняти модуль».

## Що змінено
- `src/ui/panels.ts`: `renderGunModule` — викликається в кінці `renderFighter`. Нічого не показує, коли модуля немає ні на складі, ні на перехоплювачі. Причини неактивної кнопки (рядок під кнопкою, як Т.43): «Лише у вузлі «Рубіж»: перехоплювач зараз — <статус>», «Під час бою недоступно», «Партію програно». Число «+2» — з `GUN_MODULE_DAMAGE`.
- `src/ui/research-panel.ts`: картка протоколу — «На складі: N — встановіть у панелі «Перехоплювач»».
- `README.md`: одне речення про місце модуля.
- Журнал: наявні тексти подій `gun_module_installed` / `gun_module_removed` (`src/ui/journal.ts`), категорія «Вузол».

## Перевірка
- Нові тести: `src/ui/panels.test.ts` — 5 (немає модуля; встановити; зняти; не на базі; бій і банкрутство), `src/main.ui.test.ts` — 1 (сторінка: кнопки, рядок стану, записи `#log li[data-cat="base"]`); `src/ui/research-panel.test.ts` — переписано один тест під новий текст.
- Поломки: прибраний виклик `renderGunModule` — 5 червоних; «Зняти» викликає `installGunModule` — 2 червоних.
- `npm test` — 48 файлів, 1234 тести; `tsc` (усі три конфіги), lint, format — зелені; `npm run test:e2e` — 3 сценарії зелені.

## Поза кроком
- Рядок «Наступний крок» у шапці (`src/ui/next-step.ts`) про модуль на складі не підказує — кандидат.
- «Як грати» про модуль не пише — разом із правилом евакуації (аудит Т.77) за рішенням власника.
