# Т.51. Рядок перерваного перехоплення зникає, коли зонда вже немає

Дата: 2026-11-16. Крок процесу, виконує Vibe Code за планом `docs/plans/t51-fighter-last.md`.
Рішення власника 16.11.2026, після Т.50 (дослівно з розділу «Відповідь власника» плану): «Коли зонда вже немає — рядок зникає після пройденої місії або відльоту цього зонда»

## Що зроблено

1. **Код** — `src/ui/panels.ts`, функція `renderFighter`: нова умова `probeGone` — якщо остання подія `intercept_aborted` із причиною `ufo_landed`/`ufo_lost` і зонд `last.ufoId` вже відсутній у `party.geo.ufos`, рядок `#fighter-last` не показується. Виняток `stale` (`fighter_damaged` при повному HP після ремонту) збережено; старий коментар над `stale` уточнено, бо суперечив новій умові. Тексти, id, клас, порядок елементів панелі та `src/ui/journal.ts` не змінено; `src/core/` не чіпаємо. Зонд зникає з `geo.ufos` через `ufo_left` у `geoTick` (після приземлення) або через `completeMission(…, 'перемога')` у `src/core/mission.ts`.
2. **Тести-модуль** — `src/ui/panels.test.ts`: у наявному тесті `#fighter-last` зонди подій `ufo2`/`ufo4` додано до `f.party.geo.ufos` (копія створеного ядром зонда зі зміненим `id`); новий блок Т.51.1–Т.51.5. Тексти UI у тестах — дослівні рядки (не через `geoEventText`), звірені побайтно з `src/ui/journal.ts` через python3: `ufo_landed` із зондом → рядок; без зонда → немає; такий самий рядок для `ufo_lost`; `fighter_damaged` при HP < max без зонда → рядок є; у `geo.ufos` лише інший зонд (інший id) → рядка немає (перевірка за id, а не за наявністю будь-якого зонда).
3. **Наскрізний тест** — `src/main.ui.test.ts`, новий блок у кінці файла: сід 42, пресет «норма» — активна кнопка `button.intercept` після 19 кліків `btn-tick` (запобіжник 60), старт перехоплення; ще 3 кліки (запобіжник 10) — `intercept_aborted` із причиною `ufo_landed`: текст `#fighter-last` дослівно дорівнює «✦ Зонд Розриву ufo1 приземлився — перехоплення перервано», у `#log` такий самий рядок і немає ані «зник з трекінгу», ані «Зонд Розриву ufo1 відлетів і зник»; далі кліки до появи `ufo_left` у `#log` (запобіжник 400) — і елемента `#fighter-last` немає.
4. **Навмисні поломки** — таблиця нижче (5 штук).
5. **Документи** — запис кроку в `docs/workflow.md` (після Т.50), порада в `docs/agents/common.md` (розділ «Лишее для Mistral Vibe Code»).
