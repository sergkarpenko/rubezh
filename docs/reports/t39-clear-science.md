### Що з чекліста спочатку не вдалося запустити і чому (і як обійдено)

- **`npm run test:e2e` без підготовки**: у sandbox не було жодного браузера (`/opt/pw-browsers` нема, `~/.cache/ms-playwright` порожній, системного chrome нема) — playwright не міг стартувати. Обхід: `npx playwright install chromium` скачав `chromium-1254` + headless shell (мережа до CDN Playwright працює).
- **Запуск скачаного браузера падав** (`error while loading shared libraries: libglib-2.0.so.0`): у Debian-13 контейнері нема root (`sudo` заблоковано), тому `apt-get install` / `playwright install-deps` неможливі. Обхід: скачано ~60 .deb з `deb.debian.org` (індекс `Packages.gz` trixie/main/binary-amd64) і розпаковано `dpkg -x` у `/tmp/debs/root`; запуск із `LD_LIBRARY_PATH=/tmp/debs/root/usr/lib/x86_64-linux-gnu:/tmp/debs/root/lib/x86_64-linux-gnu E2E_CHROME=$HOME/.cache/ms-playwright/chromium-1254/chrome-linux64/chrome`.
- **e2e падав на НЕЗМІНЕНОМУ main** (`#status-tab-base .tab-badge` «hidden»): у контейнері нема шрифтів, тому текстові бейджі рендеряться з висотою 0. Обхід: `fonts-dejavu-core` у той самий `/tmp/debs/root` + `FONTCONFIG_FILE` на конфіг із `<dir>/tmp/debs/root/usr/share/fonts</dir>`. Після цього e2e зелений і на main, і на гілці T.39. `/tmp` не переживає перезапуск середовища — всю підготовку треба повторити (детально — у розділі «Лише для Mistral Vibe Code» в `docs/agents/common.md`).
- Решта команд чекліста відпрацювали з першого разу після `npm ci`.

## Рішення неоднозначностей (план їх не закривав — вирішено самостійно)

1. **Ефекти простими словами** — окремі функції `plainProjectEffect` у `src/ui/effects.ts` для картки; панель «Кузня» і підказки екіпірування (`itemEffect`) **незмінні** — single source констант збережено, тексти «Кузні» не дублюються.
2. **«Зараз → стане» у plain-ефектах** — від першого оперативника загону (`ref`), як і в `projectEffect`; без ростеру — без «замість» (план: «без ростеру — без порівняння»): броня «+2 HP», око «+5 %».
3. **Розкладка довідки** — явна сітка 3 колонки (не auto-fit), перший блок на 2 рядки, 4-й блок `grid-column: 2/4` другого рядка, `@media (max-width: 760px)` — одна колонка. Виміром підтверджено вміщення на 1366×768 і 1024×768.
4. **Числівні слова для «Розширення лабораторії»** — маленькі мапи `NUM_NOM`/`NUM_GEN` (1–5) у `effects.ts`, значення беруться з `MAX_LAB_SLOTS`/`BASE_LAB_SLOTS` — «Три протоколи в роботі одночасно замість двох».
5. **Текст для `gun-module` на складі** — «На складі: N — встановіть на панелі «Перехоплювач»» (предмет не видається на вкладці «Загін»).
6. **K=1** — окремий текст «з вашим техномантом»; K≥2 — `plural(K, 'техномант', 'техноманти', 'техномантів')`.
7. **Кроки 1/2** — `scrollIntoView({ block: 'nearest' })` на `#research` / `#workshop`; крок 3 — `statusTabs.set('squad')`; `renderAll` не викликається (чиста навігація, стан гри не змінюється).
8. **`title` неактивних кнопок і hire/fire** — залишені байт-у-байт як зараз (перевірено порівнянням із `git show HEAD`), включно з «лабораторію техномагії» і «спершу: «…»».
9. **Розмір PR 1007 > 500** — план дозволяє або винести п. 3 у другий PR, або мітку `size-deviation`; власник просив **один PR**, тому: один PR #333 + мітка `size-deviation` + цей запис. Основний внесок у розмір — нові тести (380) і переписана панель (242).
