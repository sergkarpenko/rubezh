# Т.3 — Аудит правопису українською: звіт і список фіксів

**Дата:** 2026-10-16 · **Крок:** Т.3 (позафазна технічна задача, Vibe Code) · **Статус:** список фіксів затверджено власником 2026-10-16 (усі 5 пунктів рішень), застосовано тим самим текстовим PR — див. розділ «Виконання» наприкінці

## Методологія

- **Інструмент (поза репо і CI, ADR-0012):** hunspell 1.7.3 (Homebrew) + словник `uk_UA` зі репозиторія [LibreOffice dictionaries](https://github.com/LibreOffice/dictionaries) (`uk_UA.aff` + `uk_UA.dic`, master на 2026-10-16). Жодних змін у `package.json`/CI немає і не планується.
- **Відтворення перевірки окремого файла:**
  ```bash
  curl -sSLO https://raw.githubusercontent.com/LibreOffice/dictionaries/master/uk_UA/uk_UA.aff
  curl -sSLO https://raw.githubusercontent.com/LibreOffice/dictionaries/master/uk_UA/uk_UA.dic
  hunspell -d uk_UA -l <файл>
  ```
- **Токенізація:** кириличні слова з файлів (коментарі та рядкові літерали .ts/.html = видимі тексти + коментарі; .md — весь текст). Відкинуто: однолітерні фрагменти, крайові цитатні апострофи.
- **Обсяг (117 файлів):** `index.html`, `src/**` (усі .ts), `scripts/**`, md кореня (`README.md`, `AGENTS.md`), `docs/**` md — **крім** архіву `docs/prototypes/` (не чіпати) та ADR (лише звіт, записи незмінні). `coverage/` і `dist/` — артефакти збірки, поза аудитом (dist у git не входить).
- **Класифікація:** 7401 унікальний токен; 560 поза словником; із них: (а) ~440 — жаргон/транслітерації/доменні терміни → глосарій [docs/glossary.md](../glossary.md); (б) ~70 — коректні слова, яких нема у словнику (дієприкметники -учий/-ючий: «існуючий», «анімується»; «найм», «щупальця», «протиріччя», «обґрунтування» — токен розщеплюється на «об»+«рунтування» через ґ); (в) ~50 — реальні невідповідності → список фіксів нижче.
