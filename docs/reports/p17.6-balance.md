Звірка копії: без змінної CSV — байт у байт як з `main` (`cmp`).
- Частка перемог бота насичена (100 % партій на всіх пресетах і в усіх варіантах, як у п16.5) — вимірювачі: загиблі на партію, поразки місій (запущено мінус виграно) і рахунок.

## Висновки

- **Фаза 17 повертає тиск, але менше, ніж забрала Фаза 16:** загиблих на партію +31 % на «легкому» (13,4 → 17,5), +15 % на «нормі» (31,1 → 35,8), +9 % на «складному» (40,1 → 43,7); поразок місій більше — 1,3 → 2,7, 4,0 → 6,0, 6,6 → 8,2; рахунок −2,2 / −2,4 / −1,1 %. «Норма» за загиблими — між кінцем Фази 16 і її початком (48,2, звіт п16.5).
- **Внесок частин протилежний:** нові типи без туману з блокуванням (п17.2–п17.3) додавали ≈ 70 % загиблих на «нормі» (31,1 → 52,7); туман із блокуванням юнітами (п17.4) забрав ≈ 17 з них. Зміни фази без нових типів (головно туман із блокуванням; ще дозор далі огляду, ADR-0150) дуже полегшують бій із демонами: «лише демони» — 9,7 загиблих на «нормі» проти 31,1 до фази (свої живі юніти закривають огляд і вогонь демонів, ADR-0151). Тиск фази тепер тримають саме гончак, голем і око: −26 загиблих на «нормі», якщо їх прибрати.
- **Ручки чисел:** «сильніші типи» додають ≈ 7 загиблих на «нормі» і ≈ 6 на «складному»; броня голема 3 — ≈ 4,5 і 5; раніша поява — лише ≈ 2 і 1,5. Найсильніша ручка — числа типів, а не доба появи.
- Рішення власника — «Лишити як є»: бої різняться складом (мета фази), тиск помірний, а перерахунок балансу — п18.6 разом із метою кампанії, загрозою замість доби (ADR-0149 п. 3) і фінальною місією. Цей звіт — точка відліку для п18.6 поруч зі звітом п16.5: «до фази 17» і «зараз» на тих самих сідах.

## Відтворення

```sh
# стан на коміті
git worktree add --detach <тека>/before 0a61805 && ln -s <клон>/node_modules <тека>/before/node_modules
mkdir -p <тека>/runs/before/dist && cd <тека>/runs/before && node <тека>/before/scripts/run-ts.mjs <тека>/before/scripts/sim-p8.5.ts -- --seeds 120 > out.md
# варіант — у копії з перевизначенням ENEMY_KINDS зі змінної ENEMY_PATCH (sim.md), напр.:
cd <тека>/runs/strong && ENEMY_PATCH='{"hound":{"hp":9},"golem":{"hp":20},"eye":{"accuracy":[0.75]}}' \
  node <тека>/probe/scripts/run-ts.mjs <тека>/probe/scripts/sim-p8.5.ts -- --seeds 120 > out.md
```

Один прогін 120 × 3 — ≈ 31–39 с, коли поруч не більше одного іншого (у п16.5 — ≈ 170 с); три прогони одночасно на двох ядрах — ≈ 240–250 с кожен. Таблицю зведено скриптом із CSV `dist/p8.5-parties.csv` кожного прогону.
