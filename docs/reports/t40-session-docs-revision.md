| Що | Як | Результат |

| Шляхи, ADR, npm-скрипти, файли `scripts/` у трьох довідниках | скрипт звірки на гілці до і після правок | розбіжностей 0 з 0 до правок; після правок — див. нижче |
| Клас PR | `scripts/pr-class.sh` з `origin/main` | `auto` |
