## Перевірка

| Що | Як | Результат |
| --- | --- | --- |
| Шляхи, ADR, npm-скрипти, файли `scripts/` у трьох довідниках | скрипт звірки на гілці до і після правок | розбіжностей 0 до правок і 0 після |
| Клас PR | `scripts/pr-class.sh` з `origin/main` | `auto` |
| Розмір PR | `./scripts/pr-size.sh origin/main HEAD` | 0 рядків коду (лише `docs/`) |

```python
# суть скрипта звірки (запускався з /tmp, у репозиторій не входить)
for f in ['common.md', 'ui.md', 'sim.md']:
    s = open(f'docs/agents/{f}', encoding='utf-8').read()
    # 1) `docs|scripts|src|e2e|assets|.github/...` без * і <> — файл існує
    # 2) ADR-NNNN — є файл docs/adr/NNNN-*
    # 3) npm run X — X є в package.json scripts
    # 4) scripts/<ім'я>.(sh|mjs|ts|py) — файл існує
```

## Що не зроблено і чому

- **ADR про двох постійних аудиторів** — окремий PR-хвіст (ADR-0097): ADR робить PR класом `approve`, а довідники власник дозволив мержити без «схвалюю». Розділ довідника «Аудит кроку» під постійну роль править той самий PR-хвіст; тут у ньому лише записано рішення власника.
- **Постійний скрипт звірки довідників** і **доопрацювання аудитора Mistral** (читати довідники, звіт і результати чеків) — лишаються кандидатами.
