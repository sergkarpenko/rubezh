# Т.50. Ревізія документів сесії і довідників агентів після Т.40–Т.49

Дата: 2026-11-16. Крок процесу. Рішення власника (у чаті, 16.11.2026, 12:18): «Номер зонда додавай, наступне ревізія документів, схвалюю мерж» — наступний крок після Т.49 — ревізія документів сесії. Зміст ревізії узгоджено раніше: підсумки й журнал Т.44–Т.49 — в окремі документи проєкту claude.ai власника; довідники `docs/agents/` звірити з репозиторієм і перенести туди уроки, що лежали поза репозиторієм; скрипт звірки (кандидат 36) — за бажанням у тому ж кроці.

## Що зроблено

1. **Скрипт звірки** `scripts/agents-docs-check.mjs` (Node, без залежностей). Без аргументів читає `docs/agents/*.md`, з аргументами — названі файли. Перевіряє: шляхи в `…` (окремий токен або слово команди, що починається з верхньої теки чи файла репозиторію), відносні посилання Markdown, номери ADR (файл `docs/adr/NNNN-*.md`), назви `npm run …` (`package.json`). Код виходу: 0 — розбіжностей немає, 1 — є, 2 — помилка запуску чи невідомий прапорець. На диск нічого не пише.
2. **Звірка трьох довідників** на гілці від `main` = `9c9f842` — розбіжностей немає (вивід — нижче). Рядок «Звірено…» в `common.md` оновлено; там же названо, чого скрипт не бачить.
3. **Уроки, що лежали поза репозиторієм** (документ стану сесії Claude після Т.49), — у `common.md` з позначкою «спостереження сесії після мержу Т.49»: текст UI в питанні власникові — повним рядком, як у грі; старт сесії Claude — лише документ стану і файл пам'яті, кандидати — лише коли крок не обрано; «відкритих PR немає» — після перевірки командою; «схвалюю» разом зі зміною — новий коміт у тому ж PR, мерж після обов'язкових чеків без очікування джоби Mistral; цикл очікування до 7 хв (замість 9) з окремими умовами для чеків і коментаря Mistral.
4. **Розділ «Ціна сесії»** ущільнено: дев'ять абзаців «спостереження сесії після мержу Т.42–Т.48» зведено в один рядок розкладу Т.34–Т.49 і сім порад без повторів; поради, що дублювали інші розділи (старт сесії, кандидати), лишились в одному місці. Порада про скрипт звірки (Т.38) тепер посилається на готовий скрипт.
5. Документи сесії Claude в проєкті claude.ai власника (поза репозиторієм): підсумки й журнал Т.44–Т.49 — окремими файлами, перелік кандидатів оновлено (закриті 44 і 53, нові 54 і 55), документ стану скорочено.

`ui.md` і `sim.md` звірено скриптом і переглянуто — змін не потрібно.

## Перевірка

- `node scripts/agents-docs-check.mjs` на трьох довідниках: `[OK] файлів 3; шляхів 56, ADR 15, npm-скриптів 6; розбіжностей 0`.
- Навмисні поломки (тимчасовий файл у `docs/agents/` з неіснуючими шляхом `scripts/…`, ADR-0100, `npm run test:…` і посиланням `../…`; поруч — наявні ADR-0099, `npm run lint`, `npm run test:e2e` у команді з `E2E_CHROME=/opt/…`, теки й шаблони з `*`): чотири розбіжності з чотирьох, хибних немає, код виходу 1. `--help` — 0, невідомий прапорець і неіснуючий файл — 2.
- `npx prettier --check scripts/agents-docs-check.mjs` — чисто (`scripts/` поза `format:check`).

## Межі

- Скрипт не звіряє числа й факти кроків (рахунок аудиторів, токени, часи), команди поза `npm run` (обгортки, `gh api`) і шляхи, що не починаються з верхньої теки репозиторію (`/opt/…`, `~/…`, `<тека>/…`). Частину кандидата 36 «звірка чисел рахунку аудиторів із записами кроків» не зроблено.
- На `AGENTS.md` скрипт дає одну розбіжність — `src/bot.ts` у рядку, що якраз каже, що файл видалено: контексту згадки скрипт не розуміє. Тому типовий набір — лише довідники.
- Скрипт не запускається в CI і не має самоперевірки: він не пише в репозиторій і не вирішує про мерж.
