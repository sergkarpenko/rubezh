# 0104. Контрольна точка проби Vibe CLI: лишається `vibe-audit`, `mistral-audit` вимкнено

- Статус: accepted (мерж PR власником = «схвалюю» — конвенція ADR-0018/0052)
- Дата: 2026-11-20
- Частково Supersedes: ADR-0097 (другий аудитор PR — тепер `vibe-audit`, а не `mistral-audit`), ADR-0103 п. 5 (прямий виклик у `vibe-audit` прибрано)
- Доповнює: ADR-0102 п. 8 (рішення контрольної точки), ADR-0095/0098/0099 (аудитор `mistral-audit`), ADR-0100/0101 (ролі Mistral), ADR-0042 (ролі в `AGENTS.md`), ADR-0018 (зміна workflow — з ADR у точці коміту)
- Автор: Claude Code (рішення власника 20.11.2026 на старті Т.87, кнопками; задача Т.87)

## Контекст

ADR-0102 п. 8 ставить контрольну точку після 5 PR з прогоном `vibe-audit`: якщо в Vibe CLI немає жодної унікальної підтвердженої знахідки (такої, якої не дав аудитор для мержу), вимкнути обидві джоби Mistral; якщо є — новим ADR вирішити, яка з двох джоб лишається.

Рахунок за PR #397–#401 (Т.82–Т.86; записи кроків — у `docs/workflow.md`, «Технічні задачі»):

| PR | Крок | `vibe-audit`: унікальних підтверджених | `mistral-audit`: унікальних підтверджених |
| --- | --- | --- | --- |
| #397 | Т.82 | 2 | 0 |
| #398 | Т.83 | 0 | 0 |
| #399 | Т.84 | 1 | 0 (1 знахідка на першому прогоні — відхилено) |
| #400 | Т.85 | 3 | 0 |
| #401 | Т.86 | 0 | 0 |
| **Разом** | | **6** | **0** |

Основне джерело знахідок на всіх п'яти PR — аудитор для мержу (субагент Opus, ADR-0094). Прогін `vibe-audit` — ≈ 12 хв і ≈ $0,07–0,15 на пуш (ціна з `export.json`, ліміт плану Vibe). Обидві джоби з Т.84 платять ключем Vibe (ADR-0103), тож `mistral-audit` витрачає той самий місячний ліміт без жодної унікальної знахідки.

Рішення власника на старті Т.87 (кнопками, дослівно): «Лишити vibe-audit (Recommended)» — у кнопці: «mistral-audit вимкнути (workflow видалити, скрипти — заморозити як матеріал), з vibe-audit прибрати дублюючий прямий виклик»; на питання, чи переписувати застарілі розділи `AGENTS.md` про Vibe Work / Vibe Code у тому ж PR, — «Так, разом (Recommended)».

## Рішення

1. **Джобу `mistral-audit` вимкнено:** файл `.github/workflows/mistral-audit.yml` видалено. Скрипти `scripts/mistral-audit.mjs` і `scripts/mistral-audit-selftest.mjs` лишаються в репозиторії замороженими (як `scripts/vibe-*`, ADR-0100) — матеріал для занять; їх не викликає жодна джоба, змінювати не потрібно.
2. **Другий аудитор PR — `vibe-audit` (ADR-0102):** працює на кожному PR кроку поруч з аудитором для мержу; чек не обов'язковий; збій — коментар «Аудиту не було» і зелений чек. Умову мержу класу `auto` (ADR-0094) і далі виконує лише аудитор для мержу.
3. **Крок «Прямий виклик API ключем Vibe» з `.github/workflows/vibe-audit.yml` прибрано** (ADR-0103 п. 5): після Т.84 він дублював `mistral-audit`, а тепер — і сам аудит Vibe, бо збій ключа видно з коментаря «Аудиту не було». Режим `probe` у `scripts/audit-vibe-cli.mjs` лишається для ручної перевірки ключа; без файла `probe.txt` коментар починається одразу з результату аудиту.
4. **`AGENTS.md` — під фактичну схему (кандидат 84):** розділ «Розподіл ролей (ADR-0042)» замінено розділом «Ролі» (сесія агента, аудитор для мержу, `vibe-audit`, власник); розділи «Процес для Vibe Work» і «Процес для Vibe Code» видалено; кроки 2–3 «Розробки» і коментарі про чеки аудиторів переписано. Історичний текст — у тегу `iter-T.86`.
5. **Довідник `docs/agents/common.md`:** розділ «Аудит кроку» і поради про секрети — під одну джобу `vibe-audit`.
6. **Секрети:** `MISTRAL_VIBE_API_KEY` читає лише `vibe-audit`; старий `MISTRAL_API_KEY` (ключ Studio) не читає жодна джоба — видалення його і ключа в адмінці Mistral, як і раніше, за рішенням власника (ADR-0103 п. 2).

## Наслідки

- На кожен PR — два аудити: аудитор для мержу і `vibe-audit`. Місячний ліміт Vibe витрачає лише `vibe-audit`.
- Коментарі з позначкою `<!-- mistral-audit -->` на PR до цього кроку — історія; нові не з'являються.
- Самоперевірка `mistral-audit` (109 перевірок) більше не йде в CI; при зміні заморожених скриптів її треба запускати вручну.
- Повернути `mistral-audit` — новим ADR і відновленням workflow з тегу `iter-T.86`.

## Альтернативи

- **Лишити обидві джоби** — відхилено власником: `mistral-audit` за 5 PR не дав жодної унікальної підтвердженої знахідки і витрачає той самий ліміт.
- **Лишити прямий виклик у `vibe-audit` як перевірку ключа** — відхилено власником: дублює інформацію коментаря «Аудиту не було».
- **Вимкнути обидві джоби** — не відповідає п. 8 ADR-0102: `vibe-audit` дав 6 унікальних підтверджених знахідок.
- **Стабільний формат відповіді `vibe-audit`** (кандидат 87) — окремий крок.
