# 0002. Чисте ядро логіки без DOM

- Статус: accepted
- Дата: 2026-10-12

**Контекст.** Агентне генерування коду добре працює з чистою логікою і погано — з налагодженням візуальних шарів.

**Рішення.** Уся правила гри — у `src/core/` (чистий TypeScript, без DOM/Canvas); відображення — окремий шар `src/ui/`, що лише викликає API ядра.

**Наслідки.** Ядро тестується юніт-тестами без браузера; рушій-агностичність (легкий порт у Godot). UI-ітерації не ламають правила.
