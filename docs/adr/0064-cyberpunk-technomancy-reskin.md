# 0064. Тематика «кіберпанк/техномагія» — повний reskin шару відображення

- Статус: accepted (подано разом з планом Фази 12; мерж PR власником = «схвалюю» — конвенція ADR-0023/0030/0052)
- Дата: 2026-10-18
- Доповнює: ADR-0007 (мінімалістична графіка — геометрична основа лишається, змінюються палітра і матриці спрайтів), ADR-0031 (піксель-арт спрайтів кодом — редизайн тим самим механізмом), ADR-0026 (сейв-сумісність), ADR-0021/0058 (каталоги — лише значення рядкових констант), ADR-0033 (пресети — без змін)
- Автор: Vibe Work (рішення власника — сесія планування П12.1 2026-10-18)

## Контекст

MVP v0.3.0 механічно завершений (кампанія, наука, цех, звук, три рівні складності), але атмосферно гра нейтральна: «прибульці/НЛО» успадковані від X-COM-мотиву без власного сетингу. Власник ухвалив змінити тематику на кіберпанк + техномагію: усі механіки, математика, баланс, детермінізм і сейв-формат — без змін; змінюється лише відображення (тексти, палітра, спрайти). Ризики без ADR: дрейф термінології між модулями, тестами і глосарієм; випадкове зачіпання ідентифікаторів (зламані сейви/тести); зближення з торговими марками (Cyberpunk 2077, Shadowrun тощо).

## Рішення

**Сетинг.** Пізня кібернетична епоха. Над світом відкрилася Аномалія «Розрив» — джерело невідомих зонд-машин і цифрових демонів. Організація «Рубіж» — остання лінія оборони людства: кібернетика плюс техномагія (протоколи — ритуально-символічне керування силою Розриву). Перма-смерть і незворотність зберігають нуарний тон сетингу.

Мовний стиль (рішення власника): мінімум кальок — українські неологізми (техномант, потік, розрив). Фінальні формулювання уточнюються на кроці П12.6; повторюваність тримає глосарій `docs/glossary.md` (поповнюється тим самим кроком).

**Палітра (П12.7).** Нічна основа (П6.13) поглиблюється: фон синьо-чорний; неонові акценти — ціан (гравець/«Рубіж»), пурпур (Розрив), бурштин (спалахи); сітка мапи — тонкі напівпрозорі неонові лінії; краї туману — м'якші без розкриття вмісту. Глітч-акценти — лише в подієвих анімаціях (влучання, поява зонда); статику не зашумлюємо — читабельність пріоритет. Трасери неонові (механізм П6.13 без змін).

**Спрайти (П12.7).** Матриці 12×12 редизайняться кодом за ADR-0031 (без ассетів і залежностей): оперативник — силует із плащем і неоновим візором; демон Розриву — гострокутий глітч-силует із «тріщинами» світла; зонд — ромб із пульсом; приземлений зонд — глітч-осередок; вузол — вежа-маяк; перехоплювач — дельта-силует; терен геосцени — двотоновий із неоновою сіткою.

**Правила змін.**

- Ядро: лише значення українських рядкових констант (каталоги `research.ts`/`workshop.ts`, тексти `throw` і подій); структура подій логу, порядок і кількість викликів rng, математика — без змін.
- Ідентифікатори (ід юнітів, kind подій, ключі ProjectId/ItemId) англійською — НЕ змінюються.
- Твердження тестів на українські рядки синхронізуються тим самим PR (рішення власника П12.1; прецедент синхронізації тіл тестів — PR #111; окреме рішення власника зафіксовано тут наперед).
- Сейв-формат не зростає (ADR-0026): назви — відображувані значення, не ключі; сейви ≤0.3.0 вантажаться без змін.
- Авторські права: не копіювати назви, артефакти й тексти Cyberpunk 2077, Shadowrun тощо — лише жанрові атрибути (прецедент правила X-COM).

## Наслідки

- Гра отримує власну ідентичність, відокремлену від мотиву X-COM, за гарантії нульових змін поведінки: тести ізоляції (сід 42 — порядок подій і rng.state байт-у-байт) проходять разом із перейменуваннями.
- Диф мінливий, але контрольований: тексти (П12.6) і графіка (П12.7) — окремі кроки; серії PR за ADR-0061.
- Глосарій поповнюється термінами Розриву — повторюваність у майбутніх фічах.
- Зміна мапи перейменувань або правил — новий ADR із полем Supersedes.

## Альтернативи

- Лише тексти без графіки — відхилено власником: обраний повний reskin.
- Кіберсленг з кальками (нетранер, медгель, глінч) — відхилено власником: мінімум кальок, українські неологізми.
- Корпорація-конкурент або дикий ШІ як ворог — відхилено власником: обрана Аномалія «Розрив».
