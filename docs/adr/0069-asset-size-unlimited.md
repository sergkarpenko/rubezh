# 0069. Розмір графічних ассетів не обмежується — ліміти лише для кодової бази

- Статус: accepted (мерж PR власником = «схвалюю» — конвенція ADR-0023/0030/0052)
- Дата: 2026-10-18
- Замінює (частково): ADR-0068 (пункт про сумарний ліміт ≤ 500 КБ скасовано; решта пунктів ADR-0068 чинні)
- Доповнює: ADR-0036 (ліміт розміру PR — стосується коду; ADR-0061 — винятки), ADR-0060 (прев'ю гілок — валідація ассетів до мержу), ADR-0068 (ассети у шарі відображення)
- Автор: Vibe Work (рішення власника — сесія планування Ф13 2026-10-18)

## Контекст

ADR-0068 запровадив сумарний ліміт ассетів ≤ 500 КБ як засіб контролю зростання репо. Після вибору власником «багатого» 3D-стилю оформлення (два треки стилю, docs/design/style-references.md) якісні PNG-генерації 1024–2048 px перевищують цей ліміт уже на 2–3 файлах; стиснення/зменшення деградує обрану естетику. Власник 2026-10-18: «для графіки можна не враховувати розмір, а тільки для кодової бази».

## Рішення

1. **Сумарний ліміт розміру ассетів (≤ 500 КБ) скасовано.** Розмір файла не є критерієм приймання ассета; критерії — стиль (style-references.md) і затвердження власником через прев'ю (ADR-0060).
2. **Ліміти розміру стосуються тільки кодової бази**: PR ≤ 500 рядків зміни (ADR-0036/0061), ліміти розміру файлів коду — без змін. Бінарні ассети (`assets/`, PNG/WebP) у ці ліміти не входять.
3. **Решта ADR-0068 без змін**: ассети лише у шарі відображення (ADR-0002/0026), формат PNG, ліниве завантаження, фолбек кодом, тести від ассетів не залежать.
4. **Продуктивність**: якщо великий ассет фактично вплине на завантаження гри — оптимізація (стиснення, менший розмір, WebP) на кроці інтеграції за результатом прев'ю, а не заздалегідь як заборона.

## Наслідки

- Репо може рости за рахунок бінарних ассетів — свідомо приймається власником; диф ассетів бінарний, exact-байти — за git blob-hash (`scripts/verify-exact-bytes.sh`).
- Кодова гігієна не послаблюється: ADR-0036/0061 чинні для коду і текстових файлів.
- Критерій приймання П13.4 «розмір у межах ліміту ADR-0068» втрачає чинність — замінено на затвердження через прев'ю (розмір не обмежено).

## Альтернативи

- Лішити ліміт 500 КБ — відхилено власником 2026-10-18 (конфлікт з обраним стилем оформлення).
- Підняти ліміт (наприклад, до 5 МБ) — відхилено: штучна межа без критерію; власник обрав «розмір графіки не враховуємо».
