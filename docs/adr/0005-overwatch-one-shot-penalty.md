# 0005. Заступа (overwatch): один постріл зі штрафом

- Статус: accepted
- Дата: 2026-10-12

**Контекст.** Потрібен реакційний вогонь, щоб рух у зоні ворога був ризикованим — ключ до «оригінального» відчуття небезпеки. Альтернативи: кілька пострілів, витрата AP у момент пострілу.

**Рішення.** Резервація 3 AP на своєму ході; один snap-постріл зі штрафом точності ×0.7 на кожен крок ворога в дальності й лінії вогню; після пострілу заступа розряджається; скидається на початку свого ходу; смерть у русі перериває рух.

**Наслідки.** Рух ворога під прицілом стресовий, але не смертельний завжди. Симетрично для обох сторін.
