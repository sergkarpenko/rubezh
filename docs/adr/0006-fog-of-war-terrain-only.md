# 0006. Туман війни лише по рельєфу

- Статус: accepted
- Дата: 2026-10-12

**Контекст.** Юніти могли б блокувати огляд одне одного, але це ускладнює обчислення видимості і робить поведінку непередбачуваною для гравця на MVP-стадії.

**Рішення.** Видимість клітинки визначає лише рельєф (лінія Брезенхема без проміжних перешкод) у радіусі 12; стіни самі видимі, клітинки за ними — ні. Юніти огляд не блокують.

**Наслідки.** Проста й передбачувана модель; повноцінне укриття тілами — кандидат у майбутні ADR.
