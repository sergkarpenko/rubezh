# 0088. Ціни протоколів ×0,8

- Статус: accepted (мерж PR власником = «схвалюю» — конвенція ADR-0052)
- Дата: 2026-11-11
- Змінює: ціни старту протоколів у каталозі `PROJECTS` (`src/core/research.ts`; числа П11.8, ADR-0058); доповнює ADR-0087
- Автор: Claude Code (рішення власника 2026-11-11, задача Т.19)

## Контекст

Після Т.18 (ADR-0087, симетрична лінія вогню) частка виграних партій бота з політикою науки на «нормі» впала з 64,8 до 59,6 % на 480 сідах (парний z = −2,8). Власник вирішив повернути її до ≈ 65 % окремим кроком, важіль обрати за даними, «складний» не чіпати.

Probe на 480 сідах у копіях репозиторію зі зміненими константами (патерн П10.4; `docs/reports/t19-tuning.md`) показав:

- окремих значень для пресетів немає — зарплата, найм техноманта, ціни протоколів, премії й дотація є спільними константами, які пресет множить на `economyMultiplier`; змінити «норму», не зсунувши «складний», без нового механізму неможливо;
- частка перемог реагує на константи непослідовно: зарплата техноманта 20 → 15 → 10 дає 59,6 → 51,7 → 48,5 %, дотація 75 → 80 — 54,6 %, найм техноманта 80 — 69,4 %, а 60 — 64,6 %;
- ціни протоколів — єдиний важіль з однаковим знаком у всіх вимірах: ×0,8 — 65,0 %, ×0,6 — 66,0 % на «нормі», 47,5 → 52,3 % на «складному».

Варіанти, які розглянув власник: ціни протоколів ×0,8; не міняти констант; найм техноманта 80; премії за місії 120/185 (зачіпає і партії без науки). Обрано перший.

## Рішення

1. Ціни протоколів: «Композитна броня» 120 → 96, «Кібернетичне око» 90 → 72, «Регенеративний гель» 100 → 80, «Розширення лабораторії» 80 → 64, «Імпульсна граната» 140 → 112, «Гарматний модуль перехоплювача» 160 → 128. Точки, передумови, зарплата, найм, ціни цеху — без змін.
2. Окремого значення для «складного» не вводиться: він зсувається разом із «нормою» через `economyMultiplier` (власник попереджений до рішення).

## Наслідки

- Політика з наукою, 480 сідів: «норма» 59,6 → 65,0 % (парний z = +2,1), «складний» 47,5 → 52,3 % (z = +1,7), «легкий» 88,5 → 87,9 % (z = −0,4). «Норма» і «складний» повертаються приблизно до рівня перед Т.18 (64,8 і 50,4 %).
- Партії без науки не змінюються: протоколів вони не запускають (тест «партії без науки байт-у-байт» і CSV симуляцій).
- z = +2,1 — на межі шуму: зміна цін перетасовує 472 партії з 480, і зсув на 26 партій складається з 92 «стали перемогою» і 66 «перестали».
- Частка перемог бота з наукою вимірює не лише вигідність науки: дешевша зарплата і більша дотація її знижують, запас грошей на найм загону перед витратами на науку (перевірено двома варіантами політики) не підвищує. Причину не з'ясовано; до з'ясування це число — слабка підстава для подальшого тунінгу.
- Гравець бачить нові ціни в панелі «Наука» — тексти беруться з каталогу. Сейви сумісні: ціни в сейв не входять.
- Тести із зафіксованими значеннями перемірено: каталог (`research.test.ts`), сід 49 і крок бота (`party-bot.test.ts`), сід спіралі зарплат 44 → 42, баланс у UI-флоу науки (`main.ui.test.ts`).
