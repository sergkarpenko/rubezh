# 0127. Стик сусідніх стін на полі бою — чверті чинного тайла стіни

- Статус: accepted (мерж PR власником = «схвалюю» — конвенція ADR-0052)
- Дата: 2026-11-23
- Доповнює: ADR-0123 (тайли терену «мальовані»: атлас і розклад декорів без змін), ADR-0121 (поле бою «Сміливіше»), ADR-0072 (згенеровані ассети), ADR-0006 (туман — рельєф видно)
- Автор: Claude Code (Т.146; рішення власника кнопкою — мітка відповіді в записі Т.146 у `docs/workflow.md`)

## Контекст

- Стіна — тайл 48 × 48 з колонки 0 атласа `assets/metro-tiles.png` (ADR-0123): вигляд ¾ згори — ціановий кант угорі, верхня грань, темна передня грань унизу, рамка по краях.
- Мапа бою — розкидані завалені клітинки (`makeTestMap`, щільність 8 %), сусідні стіни трапляються на кожній мапі. Кожна з них малювалась тайлом цілком, тож пара чи ряд стін читалися окремими блоками з кантом і передньою гранню в кожного, а не суцільною стіною (кандидат 134, залишок серії графіки).

## Рішення

1. Варіант власника «А. Стик кодом»: стіна без сусідки-стіни за 4 напрямками — тайл цілком, як раніше; стіна із сусідкою — чотири чверті 24 × 24 на канві з того самого тайла.
2. Чверть біля сусідки по горизонталі бере стовпці ¼–¾ тайла (без бічної рамки); біля сусідки по вертикалі — рядки 8–24 тайла 48 px (верхня грань без канта і без передньої грані), розтягнуті на чверть. Отже, маса стін має кант лише згори, передню грань лише знизу, рамку лише по зовнішньому краю. Діагональні сусідки не враховуються.
3. Чиста функція `wallQuads` (`src/core/render-core.ts`, межі `WALL_FACE_Y0` / `WALL_FACE_Y1` — частки сторони тайла) дає прямокутники джерела і зсув чверті; `drawNightTerrain` (`src/render.ts`) малює їх з колонки стіни атласа.
4. Ассет, конвертер, розклад декорів, туман і фолбек без ассетів (два тони `terrainShade`) — без змін; ядро гри, сейв і детермінізм не зачеплено.

## Відхилені варіанти (рішення власника)

- «Б. Тайли стику з Gemini» — новий аркуш (кути, краї, середина), конвертер і ширший атлас: довше, ризик розбіжності стилю з чинним тайлом.
- «В. Лишити як є» — закрити кандидат без змін.

## Наслідки

- Внутрішній кут «Г» лишається без окремого малюнка: дві грані сходяться прямим кутом (видно на макеті кроку).
- Повтор середини тайла в довгому ряду стін помітний як рівна текстура без деталей — прийнятно на 20 × 20 з рідкими стінами.
