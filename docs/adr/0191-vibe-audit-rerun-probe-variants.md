- Доповнює: ADR-0102 / ADR-0104 / ADR-0105 (`vibe-audit`, повтор «лише блок JSON»), ADR-0148 (повтор запитів GitHub), ADR-0106 (`scripts/` під `tsc` і ESLint), ADR-0146 п. 6 (кандидати процесу — технічним блоком між фазами), ADR-0003 (детермінізм)

## Контекст

- **176.** `scripts/audit-vibe-cli.mjs` запускає `vibe` один раз. Код виходу, відмінний від 0 і 3, одразу дає коментар «Аудиту не було» з причиною — і тоді, коли причина тимчасова: 429 (ліміт запитів), 5xx шлюзу API чи обрив з'єднання. Повтор «лише блок JSON» (ADR-0105) тут не допомагає: він потребує `session_id` і відповіді, а прогін упав до неї. Повтор запитів GitHub (ADR-0148) API Mistral не стосується.
- **184 (залишок).** Порада `docs/agents/common.md` «`prettier --write scripts` переписав звіти `scripts/assets/*.json`» з Т.210 закрита `.prettierignore`; `npx prettier --check scripts` на `main` `afbd23f` — чистий. Зміни коду не треба — лише рядок довідника.
- **124, 224 (е).** Probe варіантів бота кінця фази (Т.230–Т.235) щоразу писали заново в `proto/` (поза репозиторієм): тека живе лише в контейнері сесії, і на Т.236 жодного з тих скриптів уже немає. `sim-p8.5.ts --policy campaign` міряє одну політику; `probe-t23.ts` має варіанти науки Т.23–Т.27, а не полів `CAMPAIGN_POLICY` Фази 22 (мережа, штат за спеціалізаціями, модулі, казан).

## Рішення

1. `vibe-audit`: прогін Vibe, що завершився кодом, відмінним від 0 і 3, з текстом помилки (`export.json` `error.message`, помилка запуску, `stderr`), який `isTransient` визнає тимчасовим — 429, 500, 502, 503, 504, «rate limit», «too many requests», «bad gateway», «service unavailable», «gateway timeout», «overloaded», `ECONNRESET`, `ETIMEDOUT`, «socket hang up», — після паузи `RERUN.pauseMs` (60 с) запускається ще раз з нуля, тими самими аргументами, у теці `rerun/`. Текст з 401, 402, 403, «billing», «unauthorized», «forbidden», «invalid api key» тимчасовим не буває.
2. Повторний прогін — один і лише тоді, коли перший тривав не довше `RERUN.maxFirstSeconds` (600 с): перший ≤ 10 хв + пауза + другий ≤ `LIMITS.seconds` + 120 с вкладаються в `timeout-minutes: 45` джоби. Повторний прогін зі збоєм — «Аудиту не було» з обома причинами; далі (без JSON, ліміт) — як раніше, з повтором «лише блок JSON» у сесії повторного прогону (ADR-0105). Рядок прогону в коментарі — обидва прогони.
3. Самоперевірка `--self-test` — шість нових перевірок: `isTransient` (так / ні), 429 → пауза 60 с і прогін у `rerun/` без `--resume` зі знахідками з нього, `export.json` першого прогону не перезаписано, два збої поспіль — обидві причини без третього прогону, перший прогін довший за 10 хв — без повтору, 402 — без повтору.
4. `scripts/probe-variants.ts`: `simulateParty` для варіантів `<ім'я>=<JSON-латка CAMPAIGN_POLICY>` (поля латки замінюють поля політики цілком), `base` — сама політика першим рядком; сіди 1..N, пресети — `--presets`; зведення за варіантом і пресетом — частка перемог, медіана доби перемоги, загиблі в середньому, банкрутства, поразки; CSV партій — `--out`; самоперевірка `--self-test`. Поза CI, як `sim-p8.5.ts`. Дерево `main` — той самий скрипт у `git worktree`; варіант числа правила ядра — як і раніше, копія з правкою константи.
5. Workflow `vibe-audit.yml`, межі `LIMITS` і `RETRY`, ядро гри, тести гри — без змін.

## Наслідки

- Тимчасовий збій API коштує до ≈ 1 хв паузи і другого прогону (до $2 за `LIMITS.price`, як перший); тривалий збій дає «Аудиту не було», як і раніше, на ≈ 1 хв пізніше. Ціна збоєм не рахується: прогін, що впав на 429, зазвичай коштує копійки.
- `isTransient` дивиться на текст: збій із тимчасовим кодом у тексті, який Vibe вигадав з іншої причини (рідко), теж повториться — один раз.
- Чек `vibe-audit` не обов'язковий (ADR-0104): зміна не впливає на мерж; на PR кроку повторний прогін видно в журналі джоби і в рядку прогону коментаря.
- Контроль `probe-variants.ts` на гілці від `main` `afbd23f`: `base`, 120 сідів × 3 пресети («легкий» / «норма» / «складний») — 99,2 / 99,2 / 91,7 % перемог, медіана доби перемоги 31 / 31 / 31, загиблих 9,6 / 12,3 / 15,9, банкрутств 0 / 1 / 4, поразок 1 / 0 / 6 — збігається з рядком «+1 лише за п'ятого» (обрано) звіту `docs/reports/p22.8-balance.md` (≈ 2,5 хв одним процесом).
- Відхилено: повторювати й код 3 (ліміт) — це не збій API, його веде повтор «лише блок JSON»; кілька повторних прогонів з наростанням паузи — тайм-аут джоби 45 хв не вміщує більше одного; переносити старі `proto/*` скрипти — їх у сесії вже немає, а `probe-t23.ts` для Фази 22 потребує іншої моделі варіантів.
