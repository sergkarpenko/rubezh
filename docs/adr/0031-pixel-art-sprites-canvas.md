# ADR-0031: Піксель-арт спрайти кодом Canvas 2D

## Статус

proposed (мерж PR власником = «схвалюю» → accepted, ADR-0023)

## Контекст

Векторні спрайти ADR-0029 (П6.7) реалізовані й валідовані, але власник вважає вигляд занадто простим (2026-10-14): потрібна піксельна графіка для солдатів, бази й НЛО — «зараз дуже просто». Обмеження незмінні: без художника, без файлів ассетів, без нових залежностей (ADR-0012), ядро `src/core/` без змін (ADR-0002), читабельність 520–720px, детермінізм логу (малювання без RNG), батарея iPad (idle → 0 перерисовок — анімаційний рушій ADR-0029 лишається чинним).

Рішення власника (сесія юзабіліті 2026-10-14): піксель-арт — кодом, без ассетів; PNG-спрайти відкинуто.

## Рішення

1. **Спрайти — матриці пікселів у коді.** Кожен спрайт (солдат, прибульчик, база, НЛО) — карта символів (рядки рівної довжини) у `src/render.ts` з палітрою «символ → колір»; кадр ходьби — окрема матриця (кількість кадрів — на розсуд агента).
2. **Offscreen-канвас + nearest-neighbor.** Матриця розгортається в offscreen-канвас низької роздільності один раз (ліниво, з кешем) і малюється через `drawImage` з `imageSmoothingEnabled = false` — крайові пікселі без розмиття; масштаб — ціле кратне (наприклад 2× у клітинці BCELL), щоб пікселі залишались рівними на 520 і 720px.
3. **Анімації — чинний AnimEngine (ADR-0029).** Ходьба чергує кадри під час анімації руху; решта анімацій (трасер, влучання, смерть, спалах дозору) без змін. Лог бою байт-у-байт незмінний; анімація — суто візуальний шар.
4. **Палітра фону — «нічний дарк» (власник, 2026-10-14).** Темно-графітовий терен, приглушена тонка сітка, яскравіші трасери/спалахи; усі кольори — константи в одному місці `render.ts`.

## Альтернативи

- **PNG-спрайти в репо** (згенеровані або намальовані) — відкинуто власником: файли ассетів, pipeline збірки, контроль версій бінарників; можливий апгрейд пізніше поверх того самого інтерфейсу малювання.
- **Деталізовані векторні силуети** — відкинуто власником («все ж давай піксельну графіку»).
- **Піксель-арт зовнішнім генератором на кроці збірки** — відкинуто: додатковий крок pipeline, фактично ті самі матриці у гіршому місці.

## Наслідки

- `render.ts`: матриці + фабрика offscreen-канвасів замість векторних примітивів для юнітів/бази/НЛО; `render.test.ts` оновлюється під нові виклики (drawImage на мок-контексті); `main.ts` — без змін оркестрації.
- Пам’ять: кілька offscreen-канвасів розміру спрайта — мізерна; малювання лишається без RNG і DOM-стану.
- Ризик: чіткість на 520px — критерій кроку П6.12; стилістична зміна знову — лише через новий ADR.
