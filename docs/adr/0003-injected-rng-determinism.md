# 0003. Детермінізм через ін'єктований RNG

- Статус: accepted
- Дата: 2026-10-12

**Контекст.** Випадковість у правилах бою потрібна, але невідтворювані тести неможливі, а реплеї й синхронізація майбутнього мультиплеєра — ні.

**Рішення.** Уся випадковість — через ін'єктований генератор (`mulberry32(seed)`) у `createGame`; жодного `Math.random()` в ядрі. Одна сія + послідовність дій = ідентичний лог.

**Наслідки.** Детерміновані тести, можливість реплеїв у майбутньому, баланс-симуляції відтворювані. Присутність сії у стані гри — обов'язкова конвенція API.
