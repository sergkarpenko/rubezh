# 0004. Формула влучності без залежності від відстані

- Статус: accepted
- Дата: 2026-10-12

**Контекст.** У оригінальному X-COM: UFO Defense шанс попадання не залежить від дистанції — лише від точності солдата і режиму пострілу; дистанція впливає лише через вибір режиму. Альтернатива — сучасні X-COM (2012+) зі штрафом дальності й укриттям.

**Рішення.** `шанс = точність солдата × модифікатор режиму` (кап 0.95, підлога 0.02). Дистанція на шанс не впливає; лінія вогню по рельєфу обов'язкова. Валідовано людиною 2026-10-12.

**Наслідки.** Простіша математика і «оригінальне» відчуття. Укриття як окремий модифікатор — можливий майбутній ADR.
