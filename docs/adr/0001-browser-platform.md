# 0001. Цільова платформа — браузер

- Статус: accepted
- Дата: 2026-10-12

**Контекст.** Потрібно швидко валідувати бойову формулу X-COM у хобі-темпі без бюджету. Кандидати: Godot 4, Unity, браузер (TS + Canvas 2D). Спеціалізовані рушії дають інструменти для великих ігор, але додаткову вагу для прототипу.

**Рішення.** Перша версія — браузерна гра на TypeScript + Canvas 2D, збірка Vite, тести vitest, без фреймворків.

**Наслідки.** Нульова установки для гравця, миттєва ітерація. Порт у Godot для Steam-версії — опція другої фази; чистота ядра (ADR-0002) мінімізує вартість порту.
