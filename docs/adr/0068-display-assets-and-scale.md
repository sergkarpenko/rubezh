# 0068. Ассети відображення і масштаб графіки

- Статус: accepted (подано разом з планом Фази 13; мерж PR власником = «схвалюю» — конвенція ADR-0023/0030/0052)
- Дата: 2026-10-18
- Замінює (частково): ADR-0007 (мінімалістична графіка — естетика тепер може переважати мінімалізм за рішенням власника), ADR-0031 (піксель-арт без файлів ассетів — у шарі відображення дозволені PNG)
- Доповнює: ADR-0002 (ядро без DOM/ассетів — межа лишається), ADR-0012 (нових залежностей немає), ADR-0026 (сейв-сумісність), ADR-0029 (idle → 0 перерисовок), ADR-0060 (прев'ю гілок — валідація ассетів до мержу), ADR-0065 (стартовий екран — лого)
- Автор: Vibe Work (рішення власника — сесія планування П13.1 2026-10-18)

## Контекст

ADR-0007/0029/0031 фіксували принцип «без художника, без файлів ассетів, усе синтезується кодом»; у ADR-0031 PNG-спрайти відхилено власником з приміткою «можливий апгрейд пізніше поверх того самого інтерфейсу малювання». Власник 2026-10-18: «можемо відійти від синтезується кодом там де це буде красивіше, також при необхідності можешь збільшувати розміри, бо зараз воно виглядає дуже замалим і не дуже естетичним». Скетч лого «РУБІЖ» (неонові градієнти, складні контури, електронні схеми) недоцільно відтворювати геометрією коду; рішення власника — PNG з генерації як ассет.

## Рішення

1. **Бінарні ассети (PNG/WebP) дозволені лише у шарі відображення**: папка `assets/` у корені; `src/core/` їх не імпортує (ADR-0002); сейв-формат і логи від ассетів не залежать (ADR-0026).
2. **Джерело** — генерація (власник або агент); кожен ассет затверджується власником через прев'ю гілок (ADR-0060) до мержу; без копіювання чужих торгових марок і артефактів (правило ADR-0064).
3. **Ліміти**: сумарно ≤ 500 КБ; формат PNG (нативне завантаження браузером, без залежностей); ліниве завантаження; **фолбек кодом** (текстовий логотип, чинний вигляд), якщо ассет недоступний — headless-тести і офлайн не ламаються.
4. **Тести не залежать від ассетів**: DOM-тести — на семантичних класах і стані; смоки ADR-0062/0063 перевіряють сторінку з фолбеком.
5. **Масштаб піксель-арту можна збільшувати** (кратний коефіцієнт масштабу, розмір матриць): критерій — читабельність і естетика на 520–720px (визначає власник через прев'ю, 2–3 ітерації); малювання без RNG; idle → 0 перерисовок (ADR-0029).
6. **Спрайти юнітів** — базовим механізмом лишаються матриці кодом (ADR-0031 чинний); PNG для окремих елементів (лого, іконки тулбара, фон стартового екрана) — за рішенням відповідного кроку фази.

## Наслідки

- Естетика більше не обмежена «усе кодом»; ядро, сейви і детермінізм повністю ізольовані від ассетів.
- Диф ассетів — бінарний; exact-байти для них — за git blob-hash (скрипт verify-exact-bytes.sh працює з індексом).
- Ризик зростання репо контрольовано лімітом 500 КБ і затвердженням кожного ассета.

## Альтернативи

- Усе і далі кодом — відхилено власником 2026-10-18.
- SVG-векторний лого кодом — відхилено: градієнти і складні контури скетчу невиразно відтворюються примітивами.
- Ассети із зовнішнього CDN — відхилено: офлайн-гра, приватність, контроль версій.
