# 0078. Мажорні версії TypeScript — поза Dependabot, лише вручну з ADR

- Статус: accepted (мерж PR власником = «схвалюю» — конвенція ADR-0023/0030/0052)
- Дата: 2026-11-10
- Доповнює: ADR-0020 (Dependabot, мерж = авторизація), ADR-0012 (процес залежностей), ADR-0016 (TypeDoc), ADR-0015 (ESLint)
- Автор: Claude Code (запит власника 2026-11-10: полагодити Dependabot-PR #259)

## Контекст

Груповий Dependabot-PR dev-залежностей двічі поспіль (PR #258, PR #259) приходив із `typescript` 5.9.3 → 7.0.2 і падав у CI ще на встановленні залежностей (`ERESOLVE`):

- `typedoc@0.28.20` (остання версія на 2026-11-10) має peer `typescript` 5.0.x–6.0.x;
- `typescript-eslint@8.72` має peer `typescript >=4.8.4 <6.1.0`.

Поки хоча б один із цих інструментів не підтримує TypeScript 7, оновити його в цьому репозиторії неможливо без `--legacy-peer-deps`, тобто без свідомо неперевіреної комбінації: TypeDoc — це публікована довідка API (ADR-0019), typescript-eslint — гейт лінту в CI (ADR-0076). Разом із TypeScript у тому самому PR застрягали сім сумісних оновлень (vitest, vite, eslint, jsdom, typescript-eslint, playwright, coverage-v8): група `dev` або проходить уся, або не проходить зовсім.

## Рішення

1. У `.github/dependabot.yml` для екосистеми `npm` додано правило `ignore`: `typescript`, `version-update:semver-major`. Мінорні й патч-оновлення TypeScript Dependabot пропонує як і раніше.
2. Мажорне оновлення TypeScript (6.x, 7.x) виконується вручну окремим кроком за ADR-0012: перевірка peer-залежностей `typedoc` і `typescript-eslint`, повний прогін гейтів ADR-0076, окремий ADR.
3. Сім сумісних оновлень із PR #259 внесено цим самим PR (коміт `chore(deps):`), перевірені локально повним набором кроків `ci.yml`. Мерж PR власником = авторизація оновлень (ADR-0020).

## Наслідки

- Груповий Dependabot-PR більше не блокується несумісним мажором TypeScript; PR #259 після мержу Dependabot закриє сам як застарілий.
- Проєкт лишається на TypeScript 5.9 до окремого рішення. Умова перегляду: `typedoc` і `typescript-eslint` оголошують підтримку потрібної мажорної версії у peer-залежностях.
- Правило стосується лише `typescript`; інші мажори (наприклад, jsdom 30 → 31 у цьому PR) ідуть звичайним шляхом ADR-0020 і перевіряються CI.
- Зняти чи змінити правило — новим ADR.

## Альтернативи

- Змержити PR #259 з `--legacy-peer-deps` або `overrides` — відкинуто: комбінація, яку автори TypeDoc і typescript-eslint не підтримують, у required-чеку.
- Коментар `@dependabot ignore typescript major version` у PR — відкинуто: правило жило б у стані Dependabot, а не в репозиторії (урок П7.5).
- Перейти на TypeScript 6.0 зараз — відкладено: окрема зміна з власною перевіркою, не частина лагодження PR #259.
