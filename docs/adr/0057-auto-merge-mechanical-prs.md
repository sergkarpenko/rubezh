# 0057. Автоматичний мерж механічних PR (рядки тегів тощо)

- Статус: accepted (рішення власника в сесії П10.2, 2026-10-16)
- Дата: 2026-10-16
- Доповнює: ADR-0052 (конвенція мержу — явний апрув власника), ADR-0028 (доставка гілка + PR), ADR-0056 (автовидалення головних гілок)
- Автор: Vibe Work (рішення — власник, ретроспектива П10.2, 2026-10-16)

## Контекст

ADR-0052 вимагає явного апруву власника на кожен PR. Після контентного мержу в сесії лишаються суто механічні PR — прецедент П10.2: PR #126 «рядок тегу iter-10.2», +1 рядок у списку тегів workflow.md, CI зелений. Практика Фаз 8–10: власник жодного разу не відхиляв і не коментував такий PR — апрув механічний, але кожна сесія зупиняється на його очікуванні (П10.2: дві зупинки на апруви в одній сесії). Окремо: `mergeable_state: blocked` на свіжому PR із уже зеленим чеком `test` — затримка статусів codecov (~хвилина), а не вимога рев'ю (урок П8.5); знімається ретраєм, звернення до власника не потребує.

## Рішення

PR суто механічного змісту — без нового змісту рішень: рядок тегу iter-X.Y у workflow.md, дрібні правки без зміни сенсу — агент мержить сам одразу після зеленого CI, без окремого апруву власника. Контентні PR (код, тести, ADR, плани, ретроспективи, зміни правил) — як і раніше лише за явним апрувом власника (ADR-0052). Механічний PR мержиться merge-комітом (ADR-0028); тег кроку на механічний merge не анкориться (урок П8.5 — тег на merge-коміті виконання критеріїв кроку). Головну гілку після мержу видаляє автоделіт репо (ADR-0056).

## Наслідки

- Цикл «мерж → тег → рядок тегу» проходиться без звернення до власника: сесія не зупиняється на апруві рядка тегу.
- Межа відповідальності: сумнів, чи PR «механічний», — трактується як контентний (апрув потрібен).
- `blocked` на свіжому PR — ретрай через ~хвилину (урок П8.5), не діагностувати як потребу в апруві.
- Зміна конвенції — лише через новий ADR із полем Supersedes.

## Альтернативи

- Статус-кво (апрув на кожен PR) — відкинуто власником у сесії П10.2: «це механічний апрув — я ні разу не заборонив його».
- GitHub Action для автоджойну — відкинуто: зайва залежність (ADR-0012) і втрата контролю merge-комітом (ADR-0028).
