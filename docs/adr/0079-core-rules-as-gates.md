# 0079. Правила ядра з AGENTS.md — як гейти: лінт-правила і компіляція без DOM

- Статус: accepted (мерж PR власником = «схвалюю» — конвенція ADR-0023/0030/0052)
- Дата: 2026-11-10
- Доповнює: ADR-0002 (чисте ядро без DOM), ADR-0003 (детермінізм через ін'єктований RNG), ADR-0038 (розділення core/UI), ADR-0015 (ESLint), ADR-0076 (гейти типів і лінту в CI)
- Автор: Claude Code (запит власника 2026-11-10, задача Т.6a)

## Контекст

AGENTS.md забороняє `Math.random()` у ядрі, порушення детермінізму і DOM/Canvas у `src/core/`. Досі ці правила перевіряла лише увага агента й рев'ю: `eslint.config.js` містив одне проєктне правило (`no-explicit-any`). Код їх дотримується — на `639fd14` у `src/core` немає жодного порушення, — але це результат дисципліни сесій, а не механізму (урок П7.5: гейт має жити в репозиторії). Що більше кроків виконують агенти без людини, то дорожче коштує правило, яке можна порушити непомітно.

## Рішення

1. **ESLint, блок `files: ['src/core/**/*.ts']`** (ядро разом із його тестами):
   - `no-restricted-properties`: `Math.random`, `Date.now`, `performance.now` (ADR-0003);
   - `no-restricted-syntax`: `new Date()` без аргументів — читає годинник (ADR-0003); `new Date(значення)` дозволено;
   - `no-restricted-imports`: будь-який імпорт `../*` — ядро не залежить від коду поза `src/core` (ADR-0002/0038).
   Повідомлення правил українською, з номером ADR.
2. **`tsconfig.core.json`**: розширює `tsconfig.json`, `lib: ["ES2022"]`, `types: []`, лише `src/core` без тестів. Ядро компілюється без `lib.dom`, тож будь-яке звернення до `document`, `window`, `HTMLElement`, Canvas-типів тощо — помилка компіляції. Тести ядра виключено: типи vitest самі потребують DOM-декларацій; тести покриває блок ESLint.
3. **CI**: крок `npx tsc --noEmit -p tsconfig.core.json` у джобі `test` (ci.yml) одразу після повної перевірки типів. Лінт-правила підхоплює наявний крок `npm run lint` (ADR-0076).
4. `tsconfig.json`, `package.json` і залежності не змінюються.
5. Локальний чекліст AGENTS.md доповнено обома командами.

## Наслідки

- Три правила ядра перестають залежати від уваги: порушення дає червоний required-чек `test`.
- Ядро не може користуватися і `console`, `setTimeout` та іншими глобалами поза ES2022 — це відповідає чинним конвенціям (події — у `state.log`, час — аргументом); якщо знадобиться — рішення окремим ADR.
- Правила стосуються лише `src/core`. Шар відображення (`src/ui`, `render.ts`, `main.ts`) зараз теж не використовує `Math.random`, але це лишається конвенцією, не гейтом.
- Поза цим ADR лишаються правила AGENTS.md про файли (заборонені файли, «workflow і package.json — лише з ADR»): вони перевіряються pre-commit хуком (правила 1, 1b, 1c) і на рівні PR ще не продубльовані.
- Зміна складу правил — новим ADR.

## Альтернативи

- `no-restricted-globals` для `document`/`window` замість окремого tsconfig — відкинуто: не бачить DOM-типів у анотаціях (`HTMLCanvasElement`, `CanvasRenderingContext2D`) і потребує ручного списку імен.
- Поширити заборону `Math.random` на весь `src/` — відкладено: це нове правило, а не механізація чинного; за окремим рішенням власника.
- Архітектурні тести (перевірка графа імпортів окремим інструментом) — відкинуто: нова залежність (ADR-0012) заради одного правила, яке покриває ESLint.
