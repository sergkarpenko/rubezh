# 0011. Ліцензія проєкту — MIT

- Статус: accepted
- Дата: 2026-10-13

**Контекст.** Репозиторій публічний (онлайн-прев'ю на GitHub Pages, ADR 0009), але не мав ліцензії: формально всі права застережено, сторонні не можуть легально використовувати, змінювати чи розгортати код. Розглянуті альтернативи: Apache-2.0 (додатковий патентний grants-розділ і файл NOTICE — обтяжливо для невеликого ігрового проєкту без патентних аспектів); GPL (copyleft обмежив би використання у закритих похідних — не мета проєкту); без ліцензії (юридична невизначеність для користувачів прев'ю).

**Рішення.** Ми використовуємо ліцензію MIT: файл `LICENSE` у корені репозиторію, власник прав — Sergii Karpenko. MIT дозвільна, коротка, стандартна для браузерних ігор і vanilla-TS проєктів; вимагає лише збереження копірайту й повідомлення ліцензії у копіях.

**Наслідки.** Код можна вільно використовувати, змінювати й розповсюджувати з атрибуцією; без гарантій. Поле `"license": "MIT"` у `package.json` не додано агентом (AGENTS.md забороняє змінювати package.json) — власник може додати його власноруч. Зміна ліцензії — новим ADR (Supersedes).
