# 0014. Pre-commit hooks — Husky + lint-staged

- Статус: accepted
- Дата: 2026-10-13

**Контекст.** Крок П9 плану Фази 2: автоматизація pre-commit hooks. Станом на цю дату в репозиторії вже працює ручний shell-hook `scripts/pre-commit.sh` (встановлювався симлінком `.git/hooks/pre-commit`, П13): перевіряє правила AGENTS.md (заборонені файли), рубіж ADR-0012 (`package.json` у коміті лише разом з `docs/adr/`), тести (`npm test`) і exact-байти. Недолік: встановлення вручну — на кожному новому клоні треба пам'ятати про `ln -s`; також немає механізму запуску перевірок лише на staged-файлах. Розглянуті альтернативи: залишити ручний shell-hook (нуль залежностей, але ручне встановлення і дублювання логіки «що запускати» у кожного клону); simple-git-hooks (легший, але менш стандартизований); lefthook (Go-бінарник, потужний, але надмірний для наших двох перевірок); pre-commit.com (Python поза стеком проєкту).

**Рішення.** Ми використовуємо Husky як менеджер git-хуків: dev-залежність `husky`, скрипт `"prepare": "husky"` (хуки встановлюються автоматично при `npm install` на будь-якому клоні), `core.hooksPath = .husky/_` (генеровані шими ігноруються: `.husky/_/` у `.gitignore`, змінено за явної авторизації власника). Хук `.husky/pre-commit` викликає наявний `scripts/pre-commit.sh` — джерело правди перевірок одне: правила AGENTS.md, рубіж ADR-0012, тести, exact-байти. Dev-залежність `lint-staged` встановлюємо зараз одним пакетом з husky (крок П9 плану), але підключаємо в хуку лише у П10 разом з ESLint/Prettier — без лінтера йому нема що запускати на staged-файлах.

**Наслідки.** Автовстановка хуків на кожному клоні; ручний симлінк більше не потрібен (інструкцію в AGENTS.md оновлено). Вплив на вагу бандлу: нуль — обидві залежності dev-only, у збиранку Vite не потрапляють. Ціна: два нові dev-пакети (транзитивно ~15); `lint-staged` до П10 лежить без конфігурації; CI (`npm ci`) виконує `prepare`, але на GitHub Actions це безпечно — husky лише пише файли в робочий каталог. Зміна рішення (наприклад, відмова від husky) — новий ADR із полем Supersedes.
