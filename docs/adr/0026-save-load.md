# 0026. Збереження партії (save/load)

- Статус: accepted
- Дата: 2026-10-13

## Контекст

Партія живе лише в пам'яті вкладки: перезавантаження сторінки втрачає прогрес (геосцена, ростер, економіка). Для MVP це критична дірка. Детермінізм ядра (один сід + дії = той самий лог) робить збереження простим і безпечним: збережений стан повністю описує подальшу траєкторію.

Рішення власника (фіксовано 2026-10-13, сесія планування Фази 5): сховище — localStorage; збереження можливе лише на геосцені (місія не переривається); лише вручну (без автозбереження); 3 слоти.

## Рішення

1. Ядро src/core/save.ts (без DOM): serializeParty(party) / deserializeParty(json). Зберігається єдиний стан партії: GeoState + Roster + EconomyState. Активна місія не зберігається — кнопки збереження активні лише на геосцені; стан бою похідний і не входить у сейв, це гарантує консистентність.
2. Формат: JSON-об'єкт з полями version (ціле, стартово 1), seed, savedAt, state. Невідома/майбутня версія або пошкоджений JSON — throw з українським текстом, без часткового стану. Зміни схеми — лише новою версією + міграцією на вході.
3. Сховище — localStorage, ключі rubezh.save.1..3. Ядро працює з абстракцією слоту (рядок-значення); конкретний localStorage підключається у main.ts — ядро лишається без DOM, тести ядра — на моках сховища.
4. Мітадані слоту (дата/сід/тик/баланс/живі солдати) — похідні від збереженого стану, окремо не дублюються.
5. Інваріанти: geo.rng не витягується; відновлена партія продовжує детерміновану траєкторію оригіналу байт-у-байт (той самий сід + тик + подальші дії = той самий лог).

## Наслідки

Що дає: прогрес переживає перезавантаження сторінки; гравець тримає до трьох партій (наприклад, для ризикованих розвилок). Ризики: приватний режим/недоступний localStorage — обробляється повідомленням у UI; ліміт ~5 МБ несуттєвий (один сейв менше 10 КБ). Ручний експорт/імпорт у файл — свідомо відкладено; формат дозволить додати його пізніше без breaking-зміни. Зміна рішення — новий ADR із полем Supersedes. Нових залежностей немає (ADR-0012 не залучено).
