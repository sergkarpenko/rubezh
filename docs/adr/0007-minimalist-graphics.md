# 0007. Мінімалістична графіка

- Статус: accepted
- Дата: 2026-10-12

**Контекст.** Хобі-проєкт у вечори без художника; арт не повинен бути в критичному шляху.

**Рішення.** Геометричні силуети, чиста палітра, спрайти-плейсхолдери. Читабельність стану поля понад естетику.

**Наслідки.** Ітерації візуалізації дешеві; оновлення стилю — пізніше без змін ядра.
