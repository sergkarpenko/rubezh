# 0126. Вікно «Налаштування» — рядок-пояснення під тумблером «Анімація» за системного «менше руху»

- Статус: accepted (мерж PR власником = «схвалюю» — конвенція ADR-0052)
- Дата: 2026-11-23
- Доповнює: ADR-0124 (тумблер, підпис і ключ без змін), ADR-0125 (спокійні подієві анімації), ADR-0073 п. 3 (тумблер ambient), ADR-0065 (вікно «Налаштування»)
- Автор: Claude Code (Т.145; рішення власника кнопкою — дослівно в записі Т.145 у `docs/workflow.md`)

## Контекст

- За системного «менше руху» (`prefers-reduced-motion: reduce`) ambient вимкнено системою, хоч би що показував тумблер «Анімація» (ADR-0124), а подієві анімації бою і геосцени — спокійні (ADR-0125). Вимкнений тумблер подієвих анімацій не гасить зовсім.
- Підпис кнопки «Анімація: увімк / вимк» показує вибір гравця (ключ `rubezh.settings.ambient`); на ньому стоять гейти e2e (Т.126, крок про повернення вкладки з фону) і тести вікна.
- Гравець із «менше руху» бачить «Анімація: увімк», а живих ефектів немає — підпис без пояснення вводить в оману (кандидат 142).

## Рішення

1. Під кнопкою `#settings-ambient` — рядок `#settings-motion-note` з текстом власника: «Увімкнено системне «менше руху»: живі ефекти вимкнено, анімації бою — спокійні.» Рядок видно лише за «менше руху»; без нього — клас `hidden`.
2. Кнопка, її підпис, ключ сховища і поведінка тумблера — без змін.
3. Залежність вікна `reducedMotion?: () => boolean` (`src/ui/settings.ts`); без неї рядка немає. `src/main.ts` передає медіазапит ADR-0124; подія `change` медіазапиту (той самий єдиний слухач Т.143, тепер після `createSettings`) викликає `settings.render()` — рядок з'являється і зникає і при відкритому вікні.
4. Стиль — чинний `.screen-dialog p`, `index.html` без змін.

## Відхилені варіанти (рішення власника)

- «Б. Підпис кнопки» — «Анімація: вимк (менше руху)» за «менше руху»: клік не дає видимої зміни, вибір гравця видно лише після зняття «менше руху».
- «В. Постійний опис» — доповнити опис секції без умов: текст про «менше руху» бачать і ті, кого він не стосується.

## Наслідки

- Гейти: тести вікна (3) і сторінки (1 — подія `change` оновлює рядок); e2e — у кроці Т.126 рядок видно за «менше руху», підпис «Анімація: увімк», зняття і повернення «менше руху» при відкритому вікні ховає і показує рядок. Поломка (без `settings.render()` у слухачі) — червоний «знято «менше руху» при відкритому вікні».
- Висота вікна «Налаштування» за «менше руху» більша на один рядок; без «менше руху» — без змін.
