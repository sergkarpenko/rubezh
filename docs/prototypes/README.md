# Прототипи React (ітерації 3.6–5.1)

**Заборонено змінювати. Довідково лише.**

## Статус

Ця директорія містить **архівні прототипи React** з попередніх ітерацій розробки (3.6–5.1), які були перенесені з прототипувального середовища як довідковий знімок.

## Заборонено

- Змінювати будь-які файли в цій директорії
- Розвивати ці прототипи далі
- Kopіювати код з цих файлів до `src/core/` або `src/main.ts` без ретельного аналізу

## Довідкова інформація

Ці файли можуть бути корисні для:

- Розуміння історії розробки інтерфейсу
- Аналізу UX-рішень, які були протестовані у прототипах
- Джерела ідей для майбутнього розвитку цільового UI (`src/main.ts`)

## Структура

- `ui_react_prototypes/` — колишня `src/ui/`:
  - `BattleWidget.tsx` (41KB) — прототип тактичного бою (ітерація 3.6)
  - `GeoWidget.tsx` (63KB) — прототип геосцени з місіями (ітерація 5.1)

## Обмеження

1. **Не сумісні з поточним стеком:** ці файли залежать від React, якого немає у `package.json`
2. **Дублювання ядра:** містять **вбудовані копії** модулів з `src/core/` (geo, combat, map, ai, mission)
   - Ці копії **могут розходитися** з актуальним ядром
   - Джерело правди — лише `src/core/`
3. **Не тестовані:** не інтегровані з поточною системою тестів (vitest)

## Як використовувати

Якщо вам потрібно перенести функціонал з прототипів до цільового UI:

1. Аналізуйте логіку у прототипі
2. Знаходьте відповідний модуль у `src/core/`
3. Реалізуйте відображення у `src/main.ts` з використанням актуального API ядра
4. Тестуйте через `npm test`
5. Валідуйте у браузері (превью на GitHub Pages)
