# Рубіж

[![codecov](https://codecov.io/gh/sergkarpenko/rubezh/graph/badge.svg)](https://codecov.io/gh/sergkarpenko/rubezh)

**Грати: https://sergkarpenko.github.io/rubezh/** — у браузері, без встановлення; десктоп і iPad.

Однокористувацька тактична стратегія за мотивами X-COM: UFO Defense у сетингу кіберпанк/техномагія (ADR-0064). Над світом відкрилася Аномалія «Розрив» — джерело зонд-машин і цифрових демонів. Ви — командир вузла «Рубіж», останньої лінії оборони людства: сенсорна сітка шукає зонди Розриву, перехоплюач знищує їх у повітрі, загін оперативників висаджується на місії. Вистояти 30 діб — перемога; банкрутство — поразка.

## Гра

- **Старт і флоу.** Стартовий екран (лого «Рубіжу»): «Нова партія» (сід і складність) / «Продовжити» (останній слот) / «Налаштування» (звук) / «Як грати»; у грі — кнопка «Меню» у топбарі. Статус-колонка — вкладками «Загін» / «Вузол» / «Система»; ефект протоколу чи предмета видно числами до старту/замовлення.
- **Геосцена.** Рухайте час — «+1 тік» (30 хв) або «+1 доба»: сенсорна сітка виявляє зонди Розриву лише в зоні досяжності. Летить — можна перехопити; приземлився — відкривається вікно місії.
- **Перехоплення.** Раундовий повітряний бій: щораунду — вибір дистанції (далека / середня / впритул) або відступ. Пошкоджений перехоплюач ремонтується у вузлі «Рубіж».
- **Місії.** Покроковий тактичний бій: очки дій (AP), три режими пострілів (швидкий / прицільний / черга), дозор (реакційний вогонь у хід демонів Розриву), туман війни; юніти і канва — піксель-арт більшого масштабу (юніти 32 px у клітинці). Перемога — премія; поразка — рани.
- **Ростер.** Оперативники набирають досвід, ветерани б'ють точніше. Перма-смерть: загиблих не повернути.
- **Наука і виробництво.** Техноманти (вербування, добове утримання) дають потік у спільний пул; лабораторія техномагії — 2 слоти (третій відкриває протокол «Розширення лабораторії»), каталог 6 протоколів. «Кузня» виготовляє предмети чергою у тіках: «Композитна броня» (+2 HP), «Кібернетичне око» (+0.05 точності), «Регенеративний гель», «Імпульсна граната», «Гарматний модуль перехоплювача» (+2 пошкодження в повітряному бою). Екіпірування — у картці оперативника; предмети загиблих втрачаються (перма-смерть наскрізна).
- **Звук.** Події бою і геосцени — WebAudio-синтез кодом (постріли, влучання, кроки, зонди, UI), тумблер у вікні «Налаштування»; на логіку гри не впливає.
- **Економіка.** Дотація 75/добу · премії за місію 110 (розвідник) / 170 (збирач) · вербування оперативника 120/100/90 (легкий/норма/складний) · ремонт перехоплюача 50 · утримання техноманта 20/добу; множник складності діє на ціни, потік — без множників.
- **Кампанія.** 30 діб, пресети складності «легкий» / «норма» / «складний» («складний» — тонші оперативники й тугіша економіка), підсумковий рахунок (100 за збитий зонд Розриву · 150 за переможну місію · 50 за живого ветерана · 0.25 за кожну грошову одиницю). Після перемоги — «Грати далі».
- **Сейви.** Три слоти в браузері; сейви ≤0.3.0 вантажаться (ключі каталогів мігруються при завантаженні, формат не зріс — ADR-0026/0064). Новачків зустрічає екран «Як грати» (кнопка «?» у топбарі — будь-коли; там же видно версію гри), по ходу з'являються короткі підказки — один раз за партію.

## Керування

Бій: бойові дії — плитки вертикального тулбара збоку; тап — вибрати клітинку (прев'ю ходу), повторний тап у ту саму клітинку — хід. Гарячі клавіші: **1** швидкий постріл · **2** прицільний · **3** черга · **O** дозор · **M** гель · **G** граната · **E** кінець ходу · **Esc** скасувати вибір (фізичні клавіші — розкладка не важлива). Мишка і дотик працюють однаково. Плитка «Авто» — авто-бій: бот грає за загін по одній дії; «Стоп» — продовжуйте вручну з досягнутого стану, «Авто» можна ввімкнути знову будь-коли.

## Детермінізм

Уся випадковість — за сідом партії: один сід + та сама послідовність дій = той самий результат. Основа тестів і майбутніх реплеїв.

## Розробка

Проєкт створено в експерименті AI-native SDLC: розробка виключно через агентів, репозиторій — джерело правди; рішення — в ADR (`docs/adr/`), робочий процес — у `docs/workflow.md`.

```bash
npm install            # також встановлює pre-commit hook (Husky)
npm test               # усі тести (vitest): ядро + DOM-флоу + наскрізна партія
npm run lint           # ESLint (src/)
npm run format:check   # Prettier (src/, index.html)
npm run build          # прод-збірка (vite → dist/)
npm run docs           # TypeDoc-довідка API (HTML у dist/api)
```

- Стек: TypeScript + Canvas 2D, Vite, без фреймворків. Тестування: vitest (700 тестів; jsdom для DOM-тестів UI), покриття v8 → Codecov.
- Структура: `src/core/` — чиста логіка гри без DOM (ядро, геосцена, місії, ШІ, сейви) + тести; `src/main.ts` + `src/ui/` — цільовий UI; `src/render.ts` + `src/core/sprites.ts` — піксель-спрайти й анімація.
- Онлайн-довідка API: https://sergkarpenko.github.io/rubezh/api/
- `docs/prototypes/` — архів React-прототипів (не змінювати; джерело правди про логіку — `src/core/`).
