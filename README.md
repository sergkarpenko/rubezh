# Рубіж

Однокористувацька тактична стратегія за мотивами X-COM: UFO Defense: глобальний стратегічний шар (час, мапа світу, база, радар, НЛО) + покроковий тактичний бій (AP, режими пострілів, заступа, туман війни).

Стовпи дизайну: незворотність наслідків (перма-смерть), інформація як ресурс, гібридний стрес двох шарів.

## Статус

Проєкт у розробці (MVP). Зроблено: бойове ядро, мапа/туман війни, ШІ прибульців, стратегічне ядро (`src/core/geo.ts`), зв'язок шарів (`src/core/mission.ts`), прототипи віджетів. Далі: економіка, дослідження, перехоплення НЛО, баланс, поліровка.

## Стек

- TypeScript + Canvas 2D, Vite, vitest, без фреймворків (цільова архітектура)

## Розробка

```bash
npm install
npm test    # тести ядра (vitest)
```

**Примітка про `src/ui/`**: це прототипи віджетів, перенесені з прототипувального середовища як довідковий знімок; вони містять вбудовані копії модулів ядра і розраховані на React-середовище, якого немає у залежностях проєкту. Джерело правди про логіку — `src/core/`. Порт відображення на ванільний TS + Canvas 2D — наступна ітерація.

## Структура

- `src/core/` — чиста логіка гри без DOM: бойове ядро, мапа/туман, ШІ, геосцена, місії + тести
- `src/ui/` — прототипи віджетів (довідково, див. примітку)
- `docs/adr/` — архітектурні рішення (ADR); записи незмінні, зміна рішення = новий ADR з полем Supersedes

## Детермінізм

Уся випадковість — через ін'єктований RNG (mulberry32, сід передається в createGame). Один сід + послідовність дій = той самий лог. Основа тестів і майбутніх реплеїв.
