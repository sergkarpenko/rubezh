# Рубіж

[![codecov](https://codecov.io/gh/sergkarpenko/rubezh/graph/badge.svg)](https://codecov.io/gh/sergkarpenko/rubezh)

**Грати: https://sergkarpenko.github.io/rubezh/** — у браузері, без встановлення; десктоп, iPad і телефон.

Однокористувацька тактична стратегія за мотивами X-COM: UFO Defense у сетингу кіберпанк/техномагія (ADR-0064). Над світом відкрилася Аномалія «Розрив» — джерело зонд-машин і цифрових демонів. Ви — командир вузла «Рубіж», останньої лінії оборони людства: сенсорна сітка шукає зонди Розриву, перехоплювачі (до трьох, в ангарах чотирьох регіонів) знищують їх у повітрі, загін оперативників висаджується на місії, а довіра регіонів тримає дотацію вузла. Перемога — виграна фінальна місія «Брама Розриву», яку відкривають три ключові протоколи за трофеї з місій; поразка — загроза Розриву 100 або банкрутство.

## Гра

- **Старт і флоу.** Стартовий екран (повноекранний арт і лого «Рубіжу»): «Нова партія» (сід і складність) / «Продовжити» (останній слот) / «Налаштування» (звук, анімація) / «Як грати»; у грі — кнопка «Меню» у топбарі (там же «Збереження»). На геосцені мапа займає ліву половину (журнал — під нею), середня колонка — «Мета кампанії», «Регіони», «Перехоплювачі», права — вкладки «Загін» / «Вузол»; на вужчих вікнах (до 1180 px) середня й права колонки складаються в одну, на телефоні — мапа, панелі, журнал згори вниз. Ефект протоколу чи предмета видно числами до старту/замовлення.
- **Геосцена.** Рухайте час — «+1 тік» (30 хв), «До події» (зупиняється на першій події: зонд, протокол, «Кузня», одужання, ремонт, штурм вузла) або «+1 доба» (зонд і штурм вузла): сенсорна сітка виявляє зонди Розриву лише в зоні досяжності. Карта світу — мальована картина «Живі береги» (однакова в кожній партії): чотири материки — регіони «Захід», «Північ», «Схід», «Південь» з пунктирними межами й довірою на мапі; значки вузла, зондів, перехоплювачів, ангарів і Брами — мальовані; навколо вузла обертається радар-розгортка (після «Пеленгу брами» — ширша зона, 6 клітинок); після «Ключа брами» біля вузла відкривається портал Брами Розриву — тап по ньому починає фінальну місію. Летить — можна перехопити; приземлився — відкривається вікно місії. Рядок «Наступний крок» підказує, що зробити далі, і веде до потрібної кнопки.
- **Регіони.** Кожна клітинка мапи належить одному з чотирьох регіонів; довіра регіону — 0–100 (старт 100): −30 за виявлений зонд, що відлетів без бою, −15 — за невиявлений, +10 за виграну місію в регіоні; збитий зонд, програна місія й евакуація довіри не змінюють. Дотація доби — сума часток регіонів за довірою (за повної довіри — як раніше, 75 × множник пресету); на довірі 0 регіон виходить назавжди і його частки більше немає. Панель «Регіони» показує довіру, частку дотації і перехоплювачі в ангарах.
- **Перехоплення.** Раундовий повітряний бій: щораунду — вибір дистанції (далека / середня / впритул) або відступ; бій одночасно — один, решта погонь чекає. Перший перехоплювач — в ангарі «Північ» (вузол «Рубіж»), ще два можна купити в «Кузні» (200 × множник науки, 48 тіків) в ангар будь-якого регіону. Картка перехоплювача — погоня обраним на виявлений зонд (старт з його ангара), бій, ремонт, гарматний модуль і «Призначити» (перебазування в інший ангар — лише на базі, одразу й безкоштовно); «Перехопити» в «Сенсорній сітці» піднімає найближчий боєготовий. Пошкоджений перехоплювач ремонтується в своєму ангарі.
- **Місії.** Покроковий тактичний бій: очки дій (AP), три режими пострілів (швидкий / прицільний / черга), дозор (реакційний вогонь у хід демонів Розриву), туман війни (живий юніт, якого видно, закриває огляд і вогонь за собою; граната летить над головами); мальовані бійці з тінню і кільцем кольору бійця під ногами, смуга HP під ногами, мальовані тайли терену (сусідні стіни зливаються в одну масу), подієві ефекти (спалах дула й віддача, іскри влучання, розчинення загиблого, вибухи, числа пошкоджень, тряска камери). Смуга загону — картки бійців з аватаром, позивним, шевроном звання, значком ролі, HP і AP; тап по видимому ворогу відкриває меню на ворогові з кнопками пострілів і гранати. Вороги — чотири типи з власним малюнком і поведінкою: демон (різак), із загрози 8 — гончак (кігті, удар лише впритул), з 17 — голем (гармата; броня 2 — кожне влучання пострілу на 2 слабше, граната б'є повністю; не більше одного на місію), з 27 — око (промінь до 16 клітинок, лише прицільний постріл, тримається на відстані); перший ворог місії — завжди демон. Перемога — премія і трофеї (по одному за кожного вбитого ворога його типу); поразка — рани. Евакуація (плитка «Евакуація» або **V**, 2 AP) — з синіх клітинок висадки: якщо поле покинув увесь загін, врятовані повертаються на базу без премії, а зонд Розриву лишається до кінця вікна посадки — місію можна повторити.
- **Загін.** Кожен оперативник має позивний і коротку біографію. Досвід — +1 за пережиту місію (зокрема евакуацію) і +1 за кожне вбивство; чотири звання — «Рекрут», «Боєць» (2 досвіду), «Сержант» (5), «Ветеран» (9), кожне нове звання — +1 HP і +0,03 точності. Зі звання «Боєць» без ролі (після місії або завантаження старого сейву) відкривається вікно вибору ролі: штурмовик — «Ривок» (+4 AP цього ходу), снайпер — «Точний постріл» (шкода ×1,5, 6 AP), медик — «Польова допомога» (+3 HP собі чи сусідові без гелю, 2 AP); дія ролі — раз за бій, плиткою тулбара («Ривок», «Точний», «Допомога») або клавішею **R**. Ростер показує шеврон звання, значок ролі й досвід до наступного звання. Перма-смерть: загиблих не повернути — журнал і картка результату пишуть рядок втрати зі статистикою бійця.
- **Наука і виробництво.** Техноманти (вербування, добове утримання) дають потік у спільний пул; лабораторія техномагії — 2 слоти (третій відкриває протокол «Розширення лабораторії»), каталог 6 протоколів і три ключові протоколи ланцюжка до Брами — «Анатомія Розриву» → «Пеленг брами» → «Ключ брами»: крім кредитів, на старті списуються трофеї. «Кузня» виготовляє предмети чергою у тіках: «Композитна броня» (+2 HP), «Кібернетичне око» (+0.05 точності), «Регенеративний гель», «Імпульсна граната», «Гарматний модуль перехоплювача» (+2 пошкодження в повітряному бою), «Перехоплювач» (до трьох разом із наявними), після «Анатомії Розриву» — «Пробивний заряд» (кредити й трофей гончака; перша атака по броньованій цілі — без броні). Екіпірування — у картці оперативника, гарматний модуль — у картці перехоплювача панелі «Перехоплювачі» (встановити / зняти в ангарі); броня й око загиблого повертаються на склад, витратники (гель, граната, «Пробивний заряд») зникають разом з ним.
- **Звук.** Події бою і геосцени — WebAudio-синтез кодом (постріли, влучання, кроки, зонди, UI), тумблер у вікні «Налаштування»; на логіку гри не впливає.
- **Анімація.** Живі деталі сцени — пульсація неонових кантів стін, дихання бійців у спокої, підсвічування смуг HP, радар-розгортка геосцени, іскри й «дихання» кільця стартового екрана; тумблер у вікні «Налаштування», у фоні вкладки гра нічого не перемальовує. Системне «менше руху» вимикає живі деталі, а анімації бою й геосцени робить спокійними — без руху й тряски (рядок про це — у вікні «Налаштування»); на логіку гри не впливає.
- **Економіка.** Старт 300 · дотація до 75/добу (частки регіонів за довірою) · премії за місію 110 (розвідник) / 170 (збирач) · за зонд, збитий у повітрі, 125 / 210 · вербування оперативника 120/100/90 (легкий/норма/складний) · ремонт перехоплювача 50 · перехоплювач 200 · утримання техноманта 10/добу. Множник економіки пресету (×1,2 / ×1 / ×0,9) діє на старт, дотацію, премії (за місію і за зонд у повітрі) й вербування; ціни науки (техноманти, протоколи, «Кузня», зокрема перехоплювач) — окремий множник (×0,5 / ×1 / ×0,9); потік — без множників.
- **Кампанія.** Мета — фінальна місія «Брама Розриву» (мапа 24 × 24, загін із трьох, шість ворогів усіх типів): її відкриває «Ключ брами», програна чи покинута евакуацією — +10 загрози і повтор через добу. Шкала загрози 0–100 (чип у шапці): +2 за добу, +6 за виявлений зонд, що відлетів без бою (+2 — невиявлений), −1 за виграну місію; на 60, 75 і 90 демони штурмують вузол — бій загону без евакуації (після «Ключа брами» — і двох турелей бази; без боєготових — програно без бою), програний штурм — +10 загрози, −30 % кредитів і половина складу; на 100 — поразка. Панель «Мета кампанії» (середня колонка геосцени) показує ланцюжок, чого бракує, трофеї і штурми. Пресети складності «легкий» / «норма» / «складний» («складний» — тонші оперативники й тугіша економіка), підсумковий рахунок (100 за збитий зонд Розриву · 150 за переможну місію · 50 за живого оперативника · 0.25 за кожен кредит) — з розкладом на екранах перемоги й поразки. Після перемоги — «Грати далі».
- **Сейви.** Три слоти в браузері; старі сейви вантажаться з міграцією на вході: ключі каталогів сейвів ≤0.3.0 (ADR-0026/0064) і ростер сейвів до v0.8.0 — досвід дорівнює вбивствам, звання — з досвіду з приростами, позивний і біографія — з пулів, роль обирається у вікні (формат v2, ADR-0147); сейви v1 і v2 — у формат v3 із загрозою, трофеями і штурмами (ADR-0155), а v1–v3 — у формат v4 з довірою регіонів (усі 100) і переліком перехоплювачів (один — в ангарі «Північ», ADR-0160, ADR-0161). Новачків зустрічає екран «Як грати» (кнопка «?» у топбарі — будь-коли; там же видно версію гри), по ходу з'являються короткі підказки — один раз за партію.

## Керування

Бій: бойові дії — плитки вертикального тулбара збоку; бійця вибирають тапом на полі або карткою смуги загону (праворуч від поля, на телефоні — над ним); тап — вибрати клітинку (прев'ю ходу), повторний тап у ту саму клітинку — хід; тап по видимому ворогу — меню на ворогові: назва з мініатюрою типу (компактна картка на малому полі — лише назва, HP числом і кнопки), HP, шкода й дальність зброї, броня, відстань, кнопки пострілів з AP і шансом влучання (стріляють одразу) і гранати. Гарячі клавіші: **1** швидкий постріл · **2** прицільний · **3** черга · **Q** наступний боєць · **O** дозор · **M** гель · **G** граната · **V** евакуація · **R** дія ролі · **E** кінець ходу · **Esc** закрити меню на ворогові чи скасувати вибір · **пробіл** / **Esc** — пропустити плашку ходу демонів (фізичні клавіші — розкладка не важлива); дія кнопкою меню на ворогові з клавіатури переводить фокус на картку стрільця. Плитка «Авто» — авто-бій: бот грає за загін по одній дії; «Стоп» — продовжуйте вручну з досягнутого стану, «Авто» можна ввімкнути знову будь-коли.

Геосцена: **T** «+1 тік» · **пробіл** «До події» · **D** «+1 доба» · **N** «Наступний крок»; кнопку, вибрану з клавіатури (Tab), натискає пробіл. Вікна над грою (меню, «Налаштування», «Як грати», «Збереження») зупиняють авто-бій, Esc їх закриває.

## Розробка

Проєкт створено в експерименті AI-native SDLC: розробка виключно через агентів, репозиторій — джерело правди; рішення — в ADR (`docs/adr/`), робочий процес і записи кроків — у `docs/workflow.md` (старші записи — у `docs/workflow-archive/`), правила для агентів — у `AGENTS.md`, практичні довідники агентів — у `docs/agents/`. Крок веде сесія Claude: код, тести, документи й PR; Mistral Vibe CLI — другий аудитор PR (джоба `vibe-audit`); власник обирає варіанти, тексти UI й дає «схвалюю» на мерж.

```bash
npm install            # також встановлює pre-commit hook (Husky)
npm test               # усі тести (vitest): ядро + DOM-флоу + наскрізна партія
npm run dev            # локальний сервер розробки (vite)
npm run lint           # ESLint (src/, scripts/, e2e/, playwright*.config.ts)
npm run format:check   # Prettier (src/, index.html, scripts/**/*.{ts,mjs}, e2e/, playwright*.config.ts, AGENTS.md, README.md)
npx tsc --noEmit       # типи з тестами; ядро без DOM — -p tsconfig.core.json, скрипти, playwright*.config.ts і e2e/smoke.e2e.ts — -p tsconfig.scripts.json
npm run build          # прод-збірка (vite → dist/)
npm run docs           # TypeDoc-довідка API (HTML у dist/api)
npm run test:e2e       # сценарій приймання в браузері (Playwright, ADR-0080)
npm run test:mutation  # мутаційне тестування ядра (StrykerJS, ADR-0083; повний прогін іде за розкладом у CI, ADR-0084)
```

- Стек: TypeScript + Canvas 2D, Vite, без фреймворків. Тестування: vitest (ядро, DOM-тести UI на jsdom, property-тести на fast-check), покриття v8 → Codecov; сценарії приймання — Playwright; мутаційне тестування ядра — StrykerJS.
- Структура: `src/core/` — чиста логіка гри без DOM (ядро, геосцена, місії, ШІ, боти, сейви, рендер-ядро) + тести; `src/main.ts` + `src/ui/` — цільовий UI (екрани, панелі, бій, смуга загону, меню на ворогові, звук, ambient, SVG-іконки й аватари); `src/render.ts` — малювання поля бою, геосцени й анімація; `assets/` — графічні ассети (атлас бійців, тайли терену, фони, картина світу й значки геосцени, рамки панелей); `scripts/` — скрипти CI, симуляцій і конвертери ассетів; `e2e/` — сценарії Playwright.
- CI: обов'язкові чеки `main` — `test` (типи, лінт, формат, тести з покриттям, збірка; для змін лише в документах і допоміжних скриптах — скорочений набір, ADR-0146), `codecov/patch`, `pr-size`, `e2e`, `shuffle` (тести в перемішаному порядку), `check` (назва тегу кроку); тег кроку (`iter-X.Y` для кроків фаз, `iter-T.N` — для решти) ставить workflow `iter-tag` після мержу; мутаційний прогін — щопонеділка.
- Онлайн-довідка API: https://sergkarpenko.github.io/rubezh/api/
- `docs/prototypes/` — архів React-прототипів (не змінювати; джерело правди про логіку — `src/core/`).
