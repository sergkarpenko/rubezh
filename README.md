# Рубіж

[![codecov](https://codecov.io/gh/sergkarpenko/rubezh/graph/badge.svg)](https://codecov.io/gh/sergkarpenko/rubezh)

**Грати: https://sergkarpenko.github.io/rubezh/** — у браузері, без встановлення; десктоп і iPad.

Однокористувацька тактична стратегія за мотивами X-COM: UFO Defense. Ви — командир прикордонної бази: радар шукає НЛО, винищувач перехоплює їх у повітрі, загін висаджується на місії. Вистояти 30 діб — перемога; банкрутство — поразка.

## Гра

- **Геосцена.** Рухайте час — «+1 тік» (30 хв) або «+1 доба»: радар виявляє НЛО лише в зоні досяжності. Летить — можна перехопити; приземлився — відкривається вікно місії.
- **Перехоплення.** Раундовий повітряний бій: щораунду — вибір дистанції (далека / середня / впритул) або відступ. Пошкоджений винищувач ремонтується на базі.
- **Місії.** Покроковий тактичний бій: очки дій (AP), три режими пострілів (швидкий / прицільний / черга), дозор (реакційний вогонь у хід прибульців), туман війни. Перемога — премія; поразка — рани.
- **Ростер.** Солдати набирають досвід, ветерани б'ють точніше. Перма-смерть: загиблих не повернути.
- **Економіка.** Дотація 75/добу · премії за місію 110 (розвідник) / 170 (збирач) · найм солдата 100 · ремонт винищувача 50.
- **Кампанія.** 30 діб, пресети «легкий» / «норма», підсумковий рахунок (100 за збитий НЛО · 150 за переможну місію · 50 за живого ветерана · 0.25 за кожну грошову одиницю). Після перемоги — «Грати далі».
- **Сейви.** Три слоти в браузері. Новачків зустрічає екран «Як грати» (кнопка «?» у топбарі — будь-коли), по ходу з'являються короткі підказки — один раз за партію.

## Керування

Бій: тап — вибрати клітинку (прев'ю ходу), повторний тап у ту саму клітинку — хід. Гарячі клавіші: **1** швидкий постріл · **2** прицільний · **3** черга · **O** дозор · **E** кінець ходу · **Esc** скасувати вибір (фізичні клавіші — розкладка не важлива). Мишка і дотик працюють однаково.

## Детермінізм

Уся випадковість — за сідом партії: один сід + та сама послідовність дій = той самий результат. Основа тестів і майбутніх реплеїв.

## Розробка

Проєкт створено в експерименті AI-native SDLC: розробка виключно через агентів, репозиторій — джерело правди; рішення — в ADR (`docs/adr/`), робочий процес — у `docs/workflow.md`.

```bash
npm install            # також встановлює pre-commit hook (Husky)
npm test               # усі тести (vitest): ядро + DOM-флоу + наскрізна партія
npm run lint           # ESLint (src/)
npm run format:check   # Prettier (src/, index.html)
npm run build          # прод-збірка (vite → dist/)
npm run docs           # TypeDoc-довідка API (HTML у dist/api)
```

- Стек: TypeScript + Canvas 2D, Vite, без фреймворків. Тестування: vitest (438 тестів; jsdom для DOM-тестів UI), покриття v8 → Codecov.
- Структура: `src/core/` — чиста логіка гри без DOM (ядро, геосцена, місії, ШІ, сейви) + тести; `src/main.ts` + `src/ui/` — цільовий UI; `src/render.ts` + `src/core/sprites.ts` — піксель-спрайти й анімація.
- Онлайн-довідка API: https://sergkarpenko.github.io/rubezh/api/
- `docs/prototypes/` — архів React-прототипів (не змінювати; джерело правди про логіку — `src/core/`).
